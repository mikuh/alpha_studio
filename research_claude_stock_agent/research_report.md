# Claude 炒股 Agent 调研报告

调研日期：2026-08-01

## 核心结论

**Claude 已经是很强的金融投研 Agent，但还不是被验证过的“自动赚钱机器”。**

Anthropic 在 2026 年发布了 10 个官方金融 Agent 模板，其中 Market Researcher、Earnings Reviewer、Model Builder 与股票研究直接相关。然而，官方仓库明确声明：这些 Agent 只生成供专业人士复核的研究成果，**不作投资推荐、不执行交易**。

能真正下单的“Claude 炒股 Agent”来自第三方拼装：Claude 负责推理，外部数据商提供实时数据，MCP/应用后端提供工具，Alpaca 等券商 API 执行订单。工程链路已经成立，但没有可靠证据证明它能长期跑赢市场。

## 生态地图

| 路线 | 代表 | 能做什么 | 证据判断 |
|---|---|---|---|
| 官方投研 Agent | Anthropic Financial Services | 筛选、财报复盘、估值、建模、研究报告 | 能力真实；官方不做推荐与交易 |
| 券商执行桥 | Alpaca MCP | 行情、账户、股票/ETF/期权/加密下单 | 接口成熟；没有自带策略或 alpha |
| 商业研究助手 | Dexter | 美股研究、筛选、回测、用户触发下单 | 功能由供应商披露；收益未独立审计 |
| 开源交易框架 | OpenAlice | 多资产研究、风控、人工批准后执行 | 架构较完整；实验性、无长期业绩 |
| 自主社区实验 | OpenProphet、SkopaqTrader | 定时唤醒、多 Agent 分析、paper/live 路径 | 能运行不等于能盈利 |
| 公开前向流水 | nightclaude | 每夜生成 S&P 500 暴露、次日成交 | 有公开负收益；周期短且账户性质不明 |

## 最值得关注的官方能力

1. Anthropic 的官方金融仓库提供股票筛选、晨会笔记、投资逻辑追踪、催化剂日历、DCF、可比公司分析等技能。
2. 实时数据可通过 FactSet、LSEG、Morningstar、S&P Capital IQ、Financial Modeling Prep 等连接器接入，但通常需要订阅/API Key。
3. Managed Agents 支持长任务、工具权限、凭据管理与审计日志，但官方仍要求人类在结果被采用前审批。
4. Claude 的消费级 Computer Use/Chrome 不适合当作交易执行器：官方明确避免或禁止投资交易。可靠执行应走受控 API，而非模拟鼠标点击券商网页。

## 业绩证据为什么不够

- Vals Finance Agent 上 Claude Opus 4.7 约 64.4%，测的是财报/SEC 文件研究问答准确率，不是收益率。
- Alpha Arena 第一季中 Claude Sonnet 4.5 约亏损 30.8%，后续赛季页面又显示正 27.7%；而且交易的是短周期加密永续合约，不是股票。结果翻转说明市场状态、提示和风险偏好对结果影响很大。
- nightclaude 在核查日约运行 67 天，组合 -4.73%，落后 SPY 约 4.31 个百分点。公开负收益值得肯定，但样本仍远不足以证明策略质量。
- 开源项目普遍能接 live key，却几乎没有第三方审计的长期逐笔实盘记录。

所以应把证据分为：接口文档和逐笔流水较强；短期比赛和 paper 前向中等；作者自报回测、截图和营销收益最弱。

## 推荐架构

最合理的个人投资路线不是“全自动 Claude 炒股”，而是：

`可信数据 → Claude 研究/候选生成 → 硬编码规则校验 → 人工批准 → 券商执行 → 独立监控与复盘`

其中风控必须独立于模型，至少包括：标的白名单、单票/组合仓位上限、单日亏损熔断、最大订单金额、禁止资金划转、默认限价单、交易时段限制、幂等订单 ID、异常行情停机、完整审计日志和一键 kill switch。

## 对个人用户的建议

1. **第一阶段：只做投研。** 用 Claude 处理公告、财报、行业比较和候选排序，要求每个关键数字带原始来源与时点。
2. **第二阶段：paper 前向验证。** 至少覆盖多种市场状态，并把手续费、滑点、停牌、成交失败和数据延迟算进去。
3. **第三阶段：人审小资金。** Agent 只能提交订单草案；人确认后执行，API 不授予提现权限。
4. **不建议：开放式全自动实盘。** 特别不要让带网页搜索能力的模型同时拥有无限制交易权限。

如果目标是 A 股，官方 Claude 金融连接器和 Alpaca 路线不能直接解决本地交易执行；更现实的是接合法的数据源，先做研究/选股/paper，再单独评估券商接口、地区监管和自动化权限。

## 最终判断

- **做研究助手：值得用。** Claude 的长文档理解、金融研究、建模和多工具协作已较成熟。
- **做信号辅助：可以试，但必须前向验证。** 模型只是策略组件，数据和规则通常比模型品牌更重要。
- **做全自动交易：技术上可行，投资上尚未被证明。** 当前最成熟的是工程基础设施，不是可持续超额收益。
