# A 股桌面投研工作台数据源调研计划

## 主问题

在 Alpha Studio 现有东方财富实时接口与聚宽 JQData 接入基础上，评估富途 OpenAPI / OpenD 能否作为 A 股桌面投研工作台的数据来源，并给出覆盖矩阵、授权边界和可靠降级策略。

## 子题

1. **现有实现盘点**：确认当前东方财富实时行情、分笔与聚宽历史/基本面/因子能力及缓存行为。
2. **富途 OpenD 官方能力**：核对沪深市场行情权限、快照/K 线/逐笔/板块/资金流/财务日历等 API 与部署限制。
3. **聚宽 JQData 官方能力**：核对历史行情、财务、宏观、因子/风险模型、授权及频率边界。
4. **产品级组合策略**：按工作台模块给出首选、补充和降级源，并定义来源、时间戳、延迟与陈旧态展示规则。

## 综合方式

以“盘中实时交互 / 盘后深度研究 / 稳态降级”三层架构形成覆盖矩阵；所有外部事实优先引用官方文档，东方财富未提供正式公共开发者 API 的部分明确标注为非官方网页接口与合规风险。
