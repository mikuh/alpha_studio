# DSL 与自动搜索政策

## FactorSpec 原则

将公式、数据域、时间语义、参数、预处理和交易方向共同视为因子身份。相同公式在不同数据快照、可得滞后、股票池或中性化配置下不是同一实验。

规范化编译链：

```text
自然语言/模板/论文
→ 受限表达式
→ parser
→ typed AST
→ 时间/单位/维度检查
→ 规范化序列化
→ 语义 hash
→ 计算 DAG
→ 执行与缓存
```

## 算子类别

### 横截面

`rank`、`zscore`、`winsorize`、`demean`、`group_rank`、`neutralize`

### 时间序列

`lag/ref`、`delta`、`rolling_mean`、`rolling_std`、`rolling_min/max`、`rolling_rank`、`decay`

### 双变量

`rolling_corr`、`rolling_cov`、`beta`、`residual`

### 安全数学

`add/subtract/multiply`、安全除法、`log1p`、有界 `power`、`abs/sign/clip`

每个算子声明输入维度、输出维度、窗口、最小观测数、NaN/Inf 行为和时间方向。

## 静态拒绝

- `lead`、负滞后或任何未来引用；
- 决策时点不可得字段；
- 时间序列与横截面维度误用；
- 未声明的复权或货币单位混合；
- 无界窗口或递归；
- 未处理除零、对数非正值和溢出；
- 自由网络、文件、数据库或系统访问；
- 由 LLM 生成且未经过沙箱和测试的任意代码。

## 搜索策略

允许：

- 经济假设模板；
- 有界参数网格；
- 遗传/演化搜索；
- MCTS/树搜索；
- LLM 多分支候选；
- 论文或研报复现和受约束变体。

要求：

- 先定义搜索空间和预算；
- 保存完整搜索树、父子谱系和失败原因；
- 将相同经济假设的不同窗口、标签、股票池和预处理归入同一 trial family；
- 记录回测次数、模型调用、token、墙钟时间和计算成本；
- 对候选多样性和语义重复同时评估；
- 不把最终 holdout 反馈给生成器；
- 让确定性执行器提供反馈；
- 采用 Pareto 选择，兼顾预测力、稳健性、成本、容量、独特性和复杂度。

## LLM 的允许角色

- 提出可证伪假设；
- 将文本映射为受限 FactorSpec；
- 解释编译或测试失败；
- 根据 discovery/validation 反馈提出下一批候选；
- 总结证据和适用边界。

禁止：

- 未执行就声称因子有效；
- 根据公式外观伪造 IC、Sharpe 或容量；
- 查看最终 holdout 后继续优化；
- 自动放宽闸门以保留候选；
- 只保留赢家和删除失败轨迹。
