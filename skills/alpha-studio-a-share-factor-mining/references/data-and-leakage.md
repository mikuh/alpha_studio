# 数据、时点与泄漏控制

## 1. 最小时间语义

对每个字段记录：

- `event_time`：经济事件发生时间；
- `published_at`：市场首次可公开获得时间；
- `available_at`：研究系统完成入库、可供策略使用时间；
- `decision_time`：信号冻结时间；
- `earliest_fill_time`：最早可成交时间。

正式实验要求：

```text
available_at <= decision_time < earliest_fill_time
```

只有日期没有时分秒时采用保守滞后。财务数据以公告可得时间为准，不以报告期为准；修订值不能覆盖历史上当时可见的版本。

## 2. 历史股票池

逐日重建当时可投资集合，包含：

- 上交所、深交所、北交所及具体板块；
- 上市、退市、暂停上市、终止上市和代码变化；
- 指数历史成分；
- ST、风险警示、停牌、上市天数；
- 当时的价格、市值、流动性和策略过滤条件。

禁止用今天仍上市的股票、当前指数成分或完整历史长度筛选过去。研究母样本和真实可交易样本分别保存。

## 3. 价格、复权与标签

明确原始价、前复权、后复权或总回报口径，以及分红、送转、配股和除权处理。

因子可使用连续复权序列，订单仿真必须使用当时真实可成交价格。二者之间需要可解释映射。

前瞻收益从最早可成交价格开始：

```text
forward_return(t, h) = exit_fill_price(t + lag + h) / entry_fill_price(t + lag) - 1
```

其中 `lag` 由信号冻结和成交假设决定。若 `close(t)` 用于因子，不能再把 `close(t)` 当成无摩擦成交价。

## 4. A股可交易性

按交易日和成交时点处理：

- 停牌、无报价和成交失败；
- 涨跌停及真实可成交量；
- ST/风险警示；
- T+1 与持仓可卖数量；
- 最小交易单位与取整；
- 佣金、税费、过户费、点差、滑点和冲击；
- 融资融券范围、借券数量、成本和召回；
- 板块、证券类型和历史制度差异。

规则会变化。只把“必须按交易日版本化处理”写死；任何当前数值、比例和费率都从交易所、监管机构或券商正式资料核验，并记录生效日期。

## 5. 常见泄漏清单

### 直接未来函数

- `lead`、负 `shift` 或未来价格；
- 用未来区间的均值/标准差处理今天；
- 用全样本分位数、均值或回归参数标准化历史样本；
- 特征窗口包含标签区间。

### 标签泄漏

- 随机打乱时间序列再切分；
- 训练样本的持有期跨入 validation/holdout；
- 同一事件或同一公告的派生样本分散到训练和测试；
- 用结果定义股票池或删除失败样本。

### 基本面与文本泄漏

- 使用最终修订财报回填首次公告；
- 使用数据库“报告期”代替发布日期；
- 新闻摘要包含盘后或次日信息；
- NLP 模型在全样本标签上训练后再生成历史特征；
- 供应商回补了当时不存在的覆盖。

### 研究过程泄漏

- 看过 holdout 后继续改窗口、方向、股票池或成本；
- 只保存赢家，不记录失败候选；
- 先按全样本 IC 选择因子，再报告同一全样本 IC；
- 多次尝试后仍使用单次检验显著性。

## 6. 必做审计

- `time-travel test`：随机历史截止日，只给当时可见数据重算；
- `universe replay`：抽查历史成分、上市/退市、ST、停牌和公司行动；
- `label-boundary test`：验证标签不跨切分边界，必要时 purge/embargo；
- `revision audit`：比较首次版本与最终版本；
- `execution replay`：从信号、下单、成交、持仓到收益逐步回放；
- `holdout audit`：记录谁、何时、为何查看 final holdout，以及之后是否修改研究。

任何无法证明 PIT 或历史股票池正确的数据，只能标记为 `RESEARCH_ONLY` 或 `not_evaluable`，不能支持生产候选结论。
