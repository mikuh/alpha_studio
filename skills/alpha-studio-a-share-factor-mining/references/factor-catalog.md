# A股量化因子目录

本目录用于产生可解释的基线候选。公式只是定义，不代表有效性；每个候选都要在 point-in-time 数据、历史股票池和严格样本外区间中计算。

## 1. 统一约定

- `P_t`：在决策时点已知且口径明确的价格；
- `R_{t,n} = P_t / P_{t-n} - 1`；
- `rank_cs`、`zscore_cs`：同日横截面处理；
- 所有窗口以交易日计；
- 因子最终方向统一为“数值越大，预期未来收益越高”；
- 价格、财务、成交、文本特征均记录真实可得时间；
- 分母为零、负值含义异常或样本不足时返回缺失，不用任意常数填充。

## 2. 价值因子

### 盈利收益率

```text
earnings_yield = 1 / PE_TTM
```

仅在市盈率口径和盈利符号有经济意义时使用。负利润公司应单独处理或标记缺失，不能与正盈利公司直接排序。

### 账面市值比

```text
book_to_price = 1 / PB
```

检查净资产为负、金融与非金融行业会计差异、商誉和资产重估影响。

### 现金流收益率

```text
cashflow_yield = operating_cash_flow_ttm / market_cap
```

使用公告后可见的滚动现金流和当时市值，关注一次性营运资本变化。

价值因子的常见失效来源：行业结构差异、价值陷阱、盈利为负、退市风险、流动性不足和长期估值制度变化。

## 3. 动量与反转

### 20 日动量

```text
momentum_20 = close_t / close_t-20 - 1
```

若收盘后形成信号，最早从下一可交易时点进入。

### 跳过近期的中期动量

```text
momentum_120_skip_20 = close_t-20 / close_t-120 - 1
```

跳过最近窗口可减少短期反转干扰。窗口必须在搜索前限定。

### 短期反转

```text
reversal_5 = -(close_t / close_t-5 - 1)
```

检查收益是否只来自涨跌停、停牌复牌、微盘股或不可成交价格。

动量/反转的常见失效来源：极端趋势或反转行情、换手过高、冲击成本、复权错误和用同一收盘价成交。

## 4. 质量因子

### 盈利能力

```text
quality_roe = roe_ttm
quality_roa = net_profit_ttm / total_assets
```

### 现金流质量

```text
cashflow_quality = operating_cash_flow_ttm / abs(net_profit_ttm)
```

利润接近零时应设安全边界。也可使用经营现金流/资产，避免分母不稳定。

### 低杠杆

```text
low_leverage = -debt_to_assets
```

金融行业不宜与工业企业直接共用同一杠杆定义。

### 盈利稳定性

```text
earnings_stability = -std(quarterly_roe, N)
```

财务特征必须按首次公告时间和历史版本拼接，不能使用后来修订的最终值回填。

## 5. 规模因子

```text
small_size = -log(float_market_cap)
```

总市值、流通市值和自由流通市值不是同一口径。小市值效应常与流动性、涨跌停、壳价值、退市风险和交易成本混合，必须做暴露与可交易性拆解。

## 6. 波动与风险因子

### 低波动

```text
low_volatility_20 = -std(daily_return, 20)
```

### 下行波动

```text
low_downside_vol = -std(min(daily_return, 0), N)
```

### 特质波动

先用市场、行业或风格模型解释收益，再取残差波动。风险因子不一定预测收益，也可用于组合风险控制；此时不要强行以 RankIC 作为唯一主指标。

## 7. 流动性与情绪

### 平均换手

```text
turnover_mean_20 = mean(turnover_rate, 20)
```

方向需由假设决定：高换手可能代表关注与趋势，也可能代表过热和未来反转。

### 换手变化

```text
turnover_change = mean(turnover, recent_N) / mean(turnover, prior_N) - 1
```

### 成交额变化

```text
amount_change = mean(amount, recent_N) / mean(amount, prior_N) - 1
```

### 市场扩散与涨停情绪

可计算行业或全市场涨停数量、上涨家数比例、连板高度、成交额扩散，再映射到个股或行业。必须使用当时可观察数据，并说明它是横截面因子、时序择时信号还是状态变量。

### 分析师与文本关注

研报数量、评级变化、情绪、公告语义和新闻热度必须处理发布时间、重复转载、实体映射、覆盖偏差、模型版本和修改历史。

## 8. 组合候选

先对单因子同向化、逐日处理和标准化：

```text
composite = sum(weight_k * zscore(factor_k))
```

首个基线优先等权。若学习权重，只使用 discovery/validation 数据，并在 final holdout 冻结。不要用同一 holdout 反复调权重。

## 9. 自定义因子

内置脚本的 `column` 类型允许评测用户已经计算好的列。自定义列仍需声明：

- 公式或代码版本；
- 输入字段与可得时间；
- 最小窗口和缺失行为；
- 预期方向；
- 是否已去极值、标准化或中性化；
- 是否包含任何未来或全样本拟合信息。

若公式需要复杂 DSL、事件研究、NLP 或高频撮合，使用客户现有引擎计算原始值，再沿统一评测流程继续。

## 10. 默认挖掘网格

有标准日频价格和成交字段、但用户没有指定公式时，可从小而明确的网格开始：

```text
momentum:        5, 10, 20, 60, 120 日
reversal:        3, 5, 10 日
low_volatility: 10, 20, 60 日
turnover_mean:   5, 20, 60 日
turnover_change: recent/prior = 5/20, 10/60
```

这只是候选生成起点，不是固定最优参数。窗口应根据预测期限、数据长度、A股交易制度和用户持有周期缩减或调整。对价值、质量、规模和预计算另类数据列，优先保留一份经济含义清晰的种子定义，再由相邻口径扩展，而不是枚举任意代数表达式。

自动挖掘时阅读 `mining-and-selection.md`，使用验证期多指标门槛、去冗余、受限组合搜索和冻结留出集协议。最终输出 Top 候选及其交易研究配置；若无候选通过，不产生虚假推荐。
