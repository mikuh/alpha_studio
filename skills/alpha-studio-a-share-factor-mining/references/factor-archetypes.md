# 因子类型与方法路由

## 1. 横截面选股因子

对象：同一时点对证券排序。

典型来源：价量、估值、质量、成长、情绪、资金流、分析师、另类数据。

默认标签：从最早可成交价格开始的明确前瞻收益区间。

核心证据：

- Pearson IC、Spearman RankIC；
- 分层收益、Top-Bottom、单调性和两端贡献；
- Fama-MacBeth 或逐期横截面回归；
- 行业、规模、beta、波动和流动性暴露；
- 中性化后预测力；
- 可交易 long-short 或 long-only 增量。

## 2. 时间序列方向因子

对象：预测单一资产或组合未来方向、收益、波动或状态。

默认方法：

- rolling/expanding 实时估计；
- 相对只使用历史信息的基准计算 OOS R²；
- HAC alpha、方向命中率和校准；
- 仓位映射、风险预算和净回测。

不要把不同资产×日期简单堆叠为独立样本。

## 3. 事件因子

对象：公告、政策、订单、业绩、问询、解禁、增减持、并购、舆情等事件后的反应。

必须定义：

- 事件首次公开时间；
- 盘前、盘中或盘后；
- 同一证券/行业的事件聚类；
- 事件窗和最早成交时间；
- 重复公告、修订和泄漏风险。

使用事件研究、匹配样本、cluster/block bootstrap 或面板回归。不要把同日同主题事件当作独立样本。

## 4. 基本面因子

对象：财务报表、业绩预告/快报、盈利预测、估值和基本面变化。

额外要求：

- point-in-time 版本；
- 公告滞后而非报告期滞后；
- 年报/季报季节性；
- 行业会计可比性；
- 极端比率、分母符号和缺失机制；
- 流通股本和公司行动同步。

## 5. 另类数据与 NLP 因子

对象：新闻、研报、公告文本、招聘、供应链、流量、地理、应用或舆情。

额外要求：

- 数据许可和可导出边界；
- 覆盖偏差和供应商生存偏差；
- 实体映射与去重；
- 文档发布时间和修改历史；
- 模型/词典/提示版本；
- 模型漂移、语言风格漂移和供应商变更。

先输出稳定的结构化特征，再进入常规因子评测。LLM 解释不能代替真实标签评估。

## 6. 微观结构与高频因子

对象：订单簿、逐笔成交、买卖压力、盘口恢复、竞价和日内状态。

额外要求：

- 交易所时钟和数据顺序；
- 可见盘口与成交回报的延迟；
- 撤单、撮合、队列和滑点假设；
- 日内季节性；
- 成交容量和市场冲击；
- 更严格的 purge、事件聚类和执行回放。

## 7. 风险与组合因子

对象：解释共同收益、协方差、尾部风险或组合状态，不一定用于直接预测个股收益。

核心证据：

- 因子收益和解释度；
- 暴露稳定性；
- 协方差和风险预测误差；
- 组合边际风险贡献；
- 压力期与跨市场稳定性；
- 与现有风险模型的增量。

## 路由原则

同一候选可以拥有多个标签，但必须指定一个 `primary_archetype`，否则无法预先冻结主检验。附加检验不得在看到结果后被重新定义为“主检验”。
