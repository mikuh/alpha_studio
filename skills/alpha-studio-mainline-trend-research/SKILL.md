# Alpha Studio 产业主线趋势研究

## 目标与边界

生成面向 A 股的每日产业主线趋势早报。核心任务不是汇总利好，也不是预测当天最可能涨停的题材，而是回答三件事：

1. 哪些产业方向具备持续数周至数月的趋势主线资格？
2. 哪些方向只有政策、新闻或短期交易资金单点驱动，因而更像脉冲行情？
3. 当前证据是否足以开放更高研究仓位权限；若不足，缺的究竟是哪一根支柱？

本 skill 是现有 `alpha-studio-daily-theme-research` 的趋势层升级版。需要判断 1–3 日资金进攻题材、集合竞价或情绪龙头时，使用盘前主题 skill；需要判断产业趋势主线、配置持续性和重仓权限时，使用本 skill。可在同一早报中把短线题材作为价格验证层，但不得用涨停热度代替定向信贷或长线资金证据。

## 核心公理

- `政策` 提供方向边界：决定能不能炒、允许不允许、是否进入国家或产业优先级。
- `定向信贷/产业投入` 验证政策虚实：辨别口头利好与真金白银，作为过滤伪题材的第一关键闸门。
- `长线机构资金` 验证持续性：区分游资和被动的一日流入，与可持续配置和趋势认可。
- `海外产业景气` 是自适应开关：全球定价赛道必须验证；纯本土赛道标记为 `N/A（不计分、不扣分）`。
- 多支柱同向且出现边际改善，才有资格定义大级别主升；单一要素驱动只能标记为短期脉冲候选。
- 多因子共振是提高仓位权限的必要条件，不是充分条件。价格结构、估值、市场风险或证据时效未过关时，仍不得输出 `允许重仓主线核心`。

## 强制护栏

- 对“今日、最新、每日早报、本周”等请求，必须核验当前数据并给出生成时间、数据截止时间和下一交易日。
- 所有政策、信贷、产业投资、机构资金、海外景气和公司业务结论都要附来源。优先一手来源，事实与推断分开写。
- 不得把以下内容误写为定向信贷：泛流动性投放、总量社融改善、单家公司再融资预案、股价上涨、ETF 申购或北向单日波动。只有能追踪到目标产业的授信、贷款、基金、财政资金、设备更新、资本开支、订单或项目落地，才构成产业投入证据。
- 不得把以下内容单独当作长线资金确认：单日龙虎榜、游资席位、单日主力净流入、短期 ETF 冲量、传闻中的机构调研。长线确认至少需要持仓/申赎/成交结构/中军趋势/多期调研或配置数据中的两个独立维度，并说明观察窗口。
- 全球定价赛道缺少海外景气确认时，最多标记为 `部分共振`，不得输出大级别主升确认；纯本土赛道则将海外支柱标记为 `N/A`。
- 每个主线都必须显示四支柱状态：`证据强度`、`边际方向`、`可信度`、`时效`、`证据缺口`。未知不能按中性分处理。
- 每份报告必须显著给出 `今日主线结论`、`主线重仓权限`、`伪题材过滤结果` 和 `最大证据缺口`，不能只给排序。
- `允许重仓主线核心` 只是一种研究权限标签，不得转化为无条件买入、具体个性化仓位或收益承诺。
- 延续性必须跨日追踪。上一期进入观察或行动清单的主线不得静默消失；必须标记 `强化`、`维持`、`降级`、`证伪` 或 `退出跟踪`。
- 最终报告必须包含：公开信息整理、模型研究框架、不构成证券投资咨询或个性化投资建议。

## 工作流

### 1. 确定模式与窗口

- 盘前早报：默认模式。使用上一交易日收盘、隔夜全球数据和当日早间新增证据。
- 盘中更新：只更新新增证据、边际变化、权限升降和失效，不重写事前判断。
- 收盘复核：冻结当日实际表现，更新支柱状态、主线连续性和次日证据清单。
- 标准正式报告默认 8 页 A4；仅在用户明确要求时生成 1–2 页简报。
- 趋势判断默认观察窗口为 20–60 个交易日，边际变化默认比较最近 5/20 个交易日；因数据频率不同可以调整，但必须说明。

### 2. 建立候选产业池

- 从国家战略、产业政策、信贷投向、财政/产业基金、企业资本开支、供需价格、订单产能、机构持仓和海外龙头指引中建立候选。
- 合并同义概念，避免把同一产业链拆成多个热点名称重复计票。
- 为每个候选先标记 `定价范围`：`本土定价`、`全球定价` 或 `混合定价`。混合定价默认开启海外景气支柱，除非能证明海外变量对收入/价格影响不重要。

### 3. 审核四支柱

生成正式报告或需要决定主线权限时，先读 `references/mainline-framework.md`。

- 政策：审核层级、约束力、配套细则、预算/目标、受益链条和落地时点。
- 定向信贷：沿着 `政策 -> 资金工具 -> 金融机构/财政主体 -> 项目/企业 -> 设备/订单/资本开支` 形成可追踪链条。
- 长线资金：审核持有窗口、资金身份、配置连续性、容量中枢和产业核心资产价格结构。
- 海外景气：仅在开关开启时审核全球价格、库存、产能利用率、订单、龙头指引、资本开支和政策约束。

对每个支柱分别记录：0–5 证据强度、`改善/持平/恶化/未知` 边际方向、0–1 可信度、证据日期、来源等级和一句反证。

### 4. 运行共振与伪题材过滤

- 结构化数据可用时运行 `scripts/score_mainlines.py`，不得手工修改脚本输出而不解释。
- 本土赛道只激活政策、定向信贷、长线资金三支柱；全球或混合赛道激活四支柱。
- 全共振要求所有激活支柱均获确认、没有恶化项，且至少两项边际改善。
- 定向信贷未确认时，无论新闻热度多高，都不得高于 `B / 部分共振 / 禁止重仓`。
- 长线资金未确认时，不得宣称趋势持续性已经确认。
- 全球/混合赛道的海外景气未确认时，不得宣称全球产业主升。
- 只有一个支柱确认时，结论必须包含 `单因子脉冲`；没有支柱确认时标记 `未形成主线`。

### 5. 给出权限而不是口号

依次输出：

1. `今日主线结论`：主线确认、趋势候选、部分共振、单因子脉冲或未形成主线。
2. `主线重仓权限`：允许重仓主线核心、中等仓位参与、轻仓验证、禁止重仓仅观察或不参与。
3. `最大证据缺口`：最阻碍升级的一根支柱及所需新增证据。
4. `升级触发` 与 `降级/失效`：必须可在后续日报中检查。

当全共振成立但价格、估值、市场风险或证据时效闸门未通过时，写成 `共振成立，重仓权限待执行闸门确认`，不得提前开放权限。

### 6. 产业链与标的映射

- 优先识别 `产业中枢`、`资本开支受益核心`、`业绩兑现核心`、`高弹性映射`，不要用连板高度定义产业主线核心。
- 每个核心标的都要验证真实业务、收入/订单/产能/客户、流动性容量和价格结构。
- 将标的真实性标为 `A/A-/B/B+/C/D`：A 为一手证据和直接链条，B 为相关但业绩弹性待确认，C 为概念映射，D 为弱相关/待验证。C/D 不能承担产业中枢或重仓核心角色。
- 为每个标的说明它验证的是哪根支柱。股票上涨只能验证价格反馈，不能单独验证政策资金落地。

### 7. 连续跟踪与反证

- 加载上一期主线台账和上一期最大证据缺口。
- 逐项比较边际变化，不因当日新闻减少就删除主线，也不因热度上升就自动升级。
- 记录新证据、过期证据、反证、状态迁移、权限迁移和下一复核时点。
- 优先寻找会推翻主线的证据：政策执行延迟、专项资金未落地、贷款用途偏离、机构减配、海外订单/价格/库存转弱、核心资产破位或估值透支。

### 8. 生成并验证报告

- 按 `references/report-structure.md` 的固定模块生成报告。
- 需要正式 HTML/PDF 时，使用 `assets/mainline-report-template.html` 与 `assets/report-style.css`；两者放在同一输出目录。
- 同步写出 `.alpha-studio-mainline.json`，结构遵循 `schemas/mainline-tracking.schema.json`。它是内部连续跟踪数据，不在最终回复中展示或链接。
- 使用 `scripts/validate_report.py` 校验 HTML 和台账；1–2 页简报传入 `--brief`。未通过前不得声称报告完成。

## 报告文风

使用中文、机构研究口吻和 `结论 -> 证据 -> 缺口 -> 触发/失效` 顺序。句子短，结论要明确。避免把“关注、看好、景气不错”当作结论；改写成可审计判断，例如：

`电网设备：政策与定向信贷均改善，长线资金仍为持平，属于趋势候选而非主升确认；新增两期主动权益增配或产业中枢放量创新高后，才升级仓位权限。`
