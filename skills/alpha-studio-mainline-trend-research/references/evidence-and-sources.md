# 证据与来源规范

## 一、证据对象

每条证据写清：`事实`、`来源`、`发布日期`、`数据截止日`、`覆盖范围`、`对应支柱`、`产业映射`、`是否为推断`。新闻发布日期不等于事实发生日期，报告必须避免把旧数据包装成新边际变化。

## 二、来源层级

### Tier 1：一手法定或官方来源

- 中国政府网、国务院、全国人大、发改委、财政部、工信部、央行、金融监管总局、证监会、交易所。
- 国家统计局、海关总署、行业主管部门和地方政府正式文件。
- 上市公司定期报告、公告、招股书、交易所问询回复、业绩会材料。
- 海外政府统计、监管机构、央行、交易所和上市公司正式披露。

### Tier 2：可核验的专业数据

- 银行、政策性金融机构、保险、基金公司披露的投向和持仓数据。
- 行业协会、产业数据库、价格/库存/出货/产能利用率数据。
- 有明确口径的行情、基金持仓、ETF 申赎和机构调研数据库。

### Tier 3：高质量二手研究

- 主流财经媒体、券商或研究机构对一手数据的整理。
- 必须能回溯到原始数据或具名消息源，不可替代关键硬闸门的一手证据。

### Tier 4：线索源

- 社交平台、论坛、概念标签、未具名渠道、截图和搜索摘要。
- 只能用于发现待核验线索，不得独立支持政策、信贷、长线资金或海外景气确认。

## 三、各支柱最低证据标准

| 支柱 | 最低确认标准 | 推荐交叉验证 |
|---|---|---|
| 政策 | 至少一条 Tier 1 正式文件或公开权威讲话，且产业映射明确 | 实施细则、责任主体、预算和时间表 |
| 定向信贷 | 至少一条 Tier 1/2 投放或产业投入证据，并能对应目标产业 | 项目/招标/订单/资本开支等第二维证据 |
| 长线资金 | 至少两个独立维度，覆盖多日或多期 | 持仓/申赎 + 中军趋势/调研/盈利预期 |
| 海外景气 | 至少一条权威行业数据或海外龙头披露 | 价格/库存/订单/资本开支中的另一维 |

## 四、时效建议

- 政策方向：在有效期内持续，但每 20 个交易日复核配套落地。
- 定向信贷：月度/季度数据按发布频率复核；项目、招标和订单用最新可得窗口。
- 长线资金：日频只做提示，至少以 5/20 日或最新披露期判断持续性。
- 海外景气：商品价格可日/周频，订单、库存、出货和指引按周/月/季度频率。

超过正常更新周期仍无新数据时，标记 `过期风险`，不得继续沿用旧的改善结论。

## 五、定向信贷闭环检查

按顺序回答：

1. 资金工具是什么？贷款、再贷款、贴息、基金、财政预算还是企业资本开支？
2. 谁提供和谁获得资金？
3. 投向是否能精确落到产业或项目，而非泛行业口号？
4. 金额是意向、授信上限、已签约、已投放还是已形成采购？
5. 是否出现招标、订单、开工、设备采购、预付款或产能利用率变化？
6. 是否存在资金挪用、重复统计或项目延期反证？

至少完成 1–4 才能把 C 记为 3；完成到 5 且有多源交叉验证，才有资格记为 4–5。

## 六、长线资金身份检查

需要同时回答“谁在买、买多久、买什么角色、是否有容量”。

- 身份不明的大单不等于机构。
- 单日北向、ETF 或主力流向只能作辅助；口径变化时须注明可比性。
- 只有小盘情绪股上涨，而高容量产业中枢和业绩核心不确认时，L 不得超过 2。
- 中军上涨但持仓、调研、申赎或盈利预期没有第二维支持时，L 最多 2。

## 七、海外景气传导检查

不要用“美股相关公司上涨”替代海外产业景气。先确认基本面变量，再确认国内映射：

`海外需求/价格/资本开支 -> 国内公司收入或订单敞口 -> 汇率/贸易/监管约束 -> A 股核心资产价格反馈`。

海外股价只能作为价格反馈，不是景气本身。

## 八、冲突处理

- 保留所有重要冲突，不取平均掩盖差异。
- 优先比较数据定义、样本范围、时间窗口和修订版本。
- 一手来源与摘要冲突时回到原文；两个一手来源口径不同则并列展示。
- 关键硬支柱冲突未解决时，将其标记为 `未知` 或降低置信度，并收紧仓位权限。

## 九、引用要求

HTML/Markdown 报告中，关键数字和结论在对应句末放直接链接；来源页按支柱分组列出标题、机构、日期、数据期和访问时间。禁止只列搜索结果页或无标题裸链接。
