# 产业主线四支柱框架

## 1. 研究对象

本框架用于识别持续数周至数月、能够承载长线资金和产业资本的 A 股产业主线。它不回答“哪个题材今天最容易涨停”，而是判断某个产业方向是否已从叙事走向资金落地，再走向长期配置和业绩兑现。

核心因果链：

`政策给方向 -> 定向信贷/产业投入把方向变成项目和订单 -> 长线资金认可持续性 -> 价格与业绩扩散`。

全球定价赛道增加一条外部约束：

`海外产业景气 -> 全球价格/订单/资本开支 -> 国内产业链收入与估值映射`。

四支柱不是简单相加。它们承担不同的证伪职责：政策回答“允许不允许”，定向信贷回答“是不是只停留在口头”，长线资金回答“能不能从交易变成趋势”，海外景气回答“全球需求会不会反向压制国内逻辑”。

## 2. 自适应支柱

### 政策方向 P

确认对象：

- 政策层级：中央/国务院、部委、地方、行业协会、公司口径。
- 约束力：法律法规、正式规划、行动方案、指导意见、会议表述、媒体吹风。
- 配套性：目标、预算、时间表、责任主体、考核指标和实施细则。
- 可投资映射：受益环节、供给约束、需求创造和竞争格局是否明确。

政策支柱确认不等于行情确认。只有方向没有资金工具时，应保持为候选。

### 定向信贷与产业投入 C

这是最重要的伪题材过滤器。优先寻找可以串成闭环的证据：

`政策目标 -> 专项贷款/再贷款/贴息/产业基金/财政资金/设备更新 -> 执行机构 -> 项目清单或企业融资 -> 招标、订单、资本开支、产能利用率`。

有效证据包括：

- 央行、金融监管部门或银行披露的行业贷款投向与增速。
- 专项再贷款、政策性金融、财政贴息、政府产业基金的实际投放。
- 重大项目清单、设备更新采购、招标和开工数据。
- 上市公司或行业龙头已执行的资本开支、订单、预付款、扩产和产能利用率。

无效替代品包括：总量 M2/社融、泛流动性宽松、股票资金净流入、再融资意向、没有投向证明的授信额度，以及只见公告未见执行的项目。

### 长线机构资金 L

目标是识别“愿意持续持有的配置资金”，而不是把每笔大单都叫机构。

优先证据：

- 主动权益基金、保险、社保、养老金、长期 ETF/指数资金的多期持仓或申赎。
- 机构调研与持仓变化在行业和核心公司间一致。
- 高流动性产业中枢连续放量、回撤受控、相对收益持续，而非单日尾盘拉升。
- 机构一致预期盈利、资本开支和配置权重持续上修。

至少使用两个独立维度，并明确窗口。单日龙虎榜、主力净流入或一日 ETF 申购只能作为短期流动性信息。

### 海外产业景气 O

先判断开关：

- `本土定价`：收入、价格、需求和政策主要由国内决定，O=`N/A`，不计分也不扣分。
- `全球定价`：商品价格、海外订单、全球产能或海外龙头资本开支显著影响国内链条，O 必须启用。
- `混合定价`：默认启用 O；只有量化证明海外收入和价格传导不重要时才能关闭。

启用后审核：全球价格、库存、订单、出货、利用率、交期、龙头指引、资本开支、贸易/监管限制和国内公司的海外敞口。

## 3. 支柱记录格式

每个激活支柱记录：

| 字段 | 取值 | 含义 |
|---|---|---|
| `strength` | 0–5 | 0 无证据；1 传闻；2 弱或间接；3 可确认；4 强；5 多源闭环 |
| `marginal` | -1/0/1/null | 恶化、持平、改善、未知 |
| `confidence` | 0–1 | 对证据真实性和映射关系的置信度 |
| `asOf` | 日期时间 | 证据截止时间 |
| `sourceTier` | 1–4 | 一手官方到低质量线索 |
| `evidence` | 列表 | 事实、来源、日期和产业映射 |
| `counterEvidence` | 列表 | 可推翻当前判断的事实 |

未知不是中性。`marginal=null` 或缺少时效数据时，不得将该支柱判定为确认。

## 4. 共振判定

单支柱确认条件：

- `strength >= 3`
- `confidence >= 0.65`
- `marginal` 为改善或持平
- 证据仍在适用期内

全共振条件：

1. 所有激活支柱均确认；
2. 没有任何激活支柱恶化或未知；
3. 至少两个激活支柱边际改善；
4. 定向信贷和长线资金必须在确认集合中；
5. 全球/混合定价赛道的海外景气必须确认。

状态映射：

| 状态 | 机械条件 | 研究含义 |
|---|---|---|
| 主升共振 | 满足全共振 | 具备大级别主升候选资格，再过执行闸门 |
| 趋势候选 | 只缺一根非恶化支柱，且 C/L 至少一项确认 | 逻辑接近闭环，等待最大缺口补齐 |
| 部分共振 | 至少两根支柱确认，但未接近全确认 | 可以跟踪或中低权限参与，不能称主升 |
| 单因子脉冲 | 仅一根支柱确认 | 更可能是政策、新闻或资金脉冲 |
| 未形成主线 | 没有支柱确认 | 不进入主线清单 |

## 5. 确定性评分

脚本先计算单支柱分：

`pillarScore = clamp(strength × 16 + marginalBonus, 0, 100) × (0.6 + 0.4 × confidence)`

其中边际改善 `+20`，持平 `0`，恶化 `-20`，未知 `-25`。总分为所有激活支柱平均值，不启用的海外支柱不进入分母。

分数只用于排序，硬闸门优先：

- C 未确认：评级最多 B，禁止重仓。
- L 未确认：评级最多 B，不能宣称趋势持续性确认。
- 全球/混合赛道 O 未确认：评级最多 B，不能宣称全球主升。
- P 未确认：不能标记主升共振。
- 任一支柱恶化：不能标记全共振。

参考评级：S ≥ 82 且全共振；A ≥ 72；B ≥ 58；C < 58。脚本会应用硬上限。

## 6. 重仓权限

权限从低到高：

1. `不参与`
2. `禁止重仓，仅观察脉冲`
3. `轻仓验证`
4. `中等仓位参与`
5. `允许重仓主线核心`

`允许重仓主线核心` 必须同时满足：

- 主升共振成立；
- 总分不低于 78；
- 价格结构、估值、市场风险和证据时效四个执行检查均为 `pass`；
- 选择的是 A/A- 真实性的产业中枢、资本开支受益核心或业绩兑现核心；
- 已定义明确的降级和退出条件。

缺少执行检查时输出 `共振成立，重仓权限待执行闸门确认`。这能保证多因子共振是重仓的必要条件，同时避免把模型分数写成自动交易指令。

## 7. 最大证据缺口

对未达到全共振的主线，不要泛泛写“仍需观察”。选出唯一最大缺口：

- 未确认的硬支柱优先级：C > L > O（开关开启时）> P。
- 已确认但恶化的支柱高于单纯缺数据的支柱。
- 给出能升级状态的最小新增证据，例如“连续两周设备更新贷款投放+项目招标扩张”，而不是“等待资金确认”。

## 8. 反证优先

每个主线至少列一项反证：政策细则延迟、资金用途偏离、贷款未形成项目、机构持仓下降、海外订单/价格转弱、资本开支下修、产业中枢破位、估值透支或供应快速扩张。反证一旦命中，应先降权限再讨论新故事。
