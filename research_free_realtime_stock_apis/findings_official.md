# 子题 1：A 股官方、交易所及持牌行情渠道

调研时间：2026-08-01（Asia/Shanghai）  
范围：上交所、深交所、北交所的股票现货实时行情，以及交易所授权的信息经营机构/持牌展示渠道。  
方法：共使用 5 个网页搜索式，优先采用交易所、交易所全资信息公司及其官方授权平台的一手材料。

## 一句话结论

**截至 2026-08，没有查到面向自然人/个人开发者、可匿名或注册后免费调用、并获得正式授权的 A 股全市场实时行情 API。** 三家交易所的正式实时行情都属于许可数据：申请主体通常必须是公司/信息经营单位，需签约并付费；展示、内部非展示使用、接口转发/再分发是不同许可用途，不能因为网页或券商 App 能免费看盘，就推定可以抓取、接入程序或对外再发布。

免费可见与免费 API 应严格区分：

- 券商 App、交易软件、财经网站向终端用户免费展示的 Level-1，通常是信息商或券商已承担授权费后的**终端展示权益**；不是给个人开发者的 Datafeed/API 授权。
- 交易所网站公开的网页行情适合人工浏览。未发现三所提供面向个人、带 API key、调用额度和开发者条款的免费实时 API；网页内部接口也不应视为开放 API。
- 深交所官方资料明确存在 **15 分钟延迟数据**层，但该页把它描述为向客户提供的数据服务，并没有声明面向个人免费开放；因此只能判为“官方有延时产品”，不能判为“免费开发者接口”。

## 一、上交所与上证所信息网络

### 1. 实时性和接入形态

上证所信息网络的 Level-1 产品页将其定义为交易规则规定的“即时行情信息”，连续竞价含最新成交价、累计量额和实时五档买卖盘；数据有 BINARY、STEP 等协议，可经上交所技术行情网关 MDGW 或上证信息客户端 VDE 接收。它是正式行情链路，不是 HTTP 公共 API。

Level-2 提供十档、逐笔成交、订单等增值数据，数据通过专网传输，官方称技术系统为毫秒级时延。终端网络、授权信息商加工与客户端刷新仍会引入额外时延，所以不能把“毫秒级发布系统”理解成所有零售终端都具备毫秒级端到端 SLA。

来源：

- [上证所 Level-1 行情产品页](https://www.sseinfo.com/services/assortment/level1/)
- [上证所 Level-2 行情产品页](https://www.sseinfo.com/services/assortment/level2/)
- [上证行情服务首页及接口文档入口](https://www.sseinfo.com/services/assortment/market/)

### 2. 为什么不是个人免费 API

Level-1 申请指引要求申请者为“合法成立的信息经营单位”，并同时具备固定营业场所、信息经营所需资质/许可、50 万元以上注册资金和可靠技术服务能力。这排除了自然人以个人开发者身份直接申请正式经营许可。

价目表显示：

- 境内 Level-1：展示许可费 15 万元/年 + 用户使用费 15 万元/年（终端类型不同还会累加）。
- Level-2 展示：许可费 35 万元/年，另有按终端计费及保底费。
- Level-2 非展示自用：每指定机房 24 万元/年；每套 VDE 技术服务费 6 万元/年；机房内转发和接口转发另计。
- 上证智能“云数聚”能以 API 提供实时行情，但官方价格为 1 万元/月/用户（首年半价），不是免费 API。

来源：

- [上证所 Level-1 行情业务申请/许可指引](https://bsp.sseinfo.com/business/?id=1671080829401092098)
- [上证所信息网络产品服务价格](https://www.sseinfo.com/services/cpfwjg/)
- [上证所 Level-1 许可单位公示](https://bsp.sseinfo.com/license/?definitionId=447052632968665861&type=1)

### 3. 授权、展示、再分发

上交所与深交所联合声明称，交易所市场产生的证券信息归交易所所有；未经许可，任何人不得复制、传输、转让、使用、许可他人使用或开发金融/信息产品。除交易所会员在法定经纪业务场所现场公布外，机构或个人接收、使用、经营沪深证券信息都需分别向上证所信息网络或深圳证券信息申请许可。

上证价目表进一步把 Level-2 非展示用途拆为自用、机房内转发和接口转发，说明“合法买到/看到行情”不自动附带把数据经 API 给别人使用的权利。

来源：

- [上证所信息网络授权声明（含沪深交易所联合声明）](https://www.sseinfo.com/aboutus/authstatement/)
- [上证所信息网络产品服务价格（展示、非展示及接口转发定义）](https://www.sseinfo.com/services/cpfwjg/)

## 二、深交所与深圳证券信息

### 1. 实时、延时和日终层

深交所 2026 年交易规则规定，交易所每个交易日实时发布证券交易即时行情和指数；连续竞价即时行情为最新价、累计量额和实时五档买卖盘。规则同时规定即时行情通过深交所许可的通信系统传输，交易参与人应在许可范围内使用。

深交所官方英文 Data Services 页明确列出三类 Level-1：

- Real-time Data：实时；
- Delayed Data：15 分钟延迟；
- End-of-day Data：日终。

该页说明产品层级与延迟，但没有给出个人免费 API、自助注册、API key 或免费调用额度。因此不宜将“15 分钟延迟产品”直接当作免费开放接口。

来源：

- [《深圳证券交易所交易规则（2026 年修订）》PDF，第 5 章交易信息](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)
- [SZSE Data Services（实时、15 分钟延时、日终）](https://www.szse.cn/English/services/dataServices/index.html)
- [深交所行情接口规范入口](https://www.szse.cn/marketServices/technicalservice/interface/index_1.html)

### 2. 申请门槛与费用

深圳证券信息官方授权平台的股票现货基本行情申请指引要求：固定营业场所、相关信息经营资质、注册资金不低于 50 万元、近三年无不良经营记录；流程包含申请、审核与公示、签订专有信息许可合同、缴费和颁证。

境内基本行情收费标准按展示形态分别计费：网页类 30 万元/年、电脑类 30 万元/年、无线类 30 万元/年；同时申请两类以上可申请总额八折。应用定义也很清楚：无线类包括手机 App 与页面嵌入，电脑类包括桌面/平板应用，网页类仅限浏览器网页揭示。

因此，个人在券商/网站免费看到深市 Level-1，只表示他是某一许可终端的最终用户，不表示他取得了网页、电脑、无线应用开发或数据再分发权。

来源：

- [股票现货基本行情申请指引](http://www.cninfo.com.cn/fwsq/hq/sqlc.htm)
- [境内股票现货基本行情收费标准](http://www.cninfo.com.cn/fwsq/hq/sfbz.htm)
- [股票现货基本行情介绍及应用类型](http://www.cninfo.com.cn/fwsq/hq/jb.htm)
- [深市股票现货基本行情许可单位公示](http://www.cninfo.com.cn/fwsq/hq/qsmd.htm)

### 3. 使用与传播限制

2026 年交易规则第 5.1.3 条规定：交易信息归深交所所有，未经许可任何机构和个人不得使用和传播；经许可使用者，未经同意也不得把交易信息提供给其他机构和个人使用或传播。这里直接否定了“网页能访问，所以可以无授权抓取并给自己的用户调用”的推论。

来源：

- [《深圳证券交易所交易规则（2026 年修订）》PDF](https://docs.static.szse.cn/www/lawrules/rule/trade/current/W020260424690713155663.pdf)

## 三、北交所与中证股转科技

北交所和全国股转系统授权中证股转科技独家管理、经营证券行情信息。官方境内行情授权指南称：

- 未经许可，任何单位和个人不得发布、使用和传播行情信息；
- Level-1 申请人必须具有公司法人资格和固定经营场所；
- 注册资金不低于 100 万元；
- 对行情展示和指数编制分类收费；
- 超出许可范围使用时，可被切断行情接入并追责。

附件价目表显示，北交所/全国股转系统 Level-1 行情展示的展示许可费为 15 万元/年，用户使用费为 15 万元/年/类。故无个人免费正式接口。

来源：

- [北交所境内行情授权指南](https://www.bse.cn/application/guide.html)
- [北交所和全国股转系统 Level-1 境内许可经营价目表 PDF](https://www.bse.cn/uploads/6/file/public/202211/20221104183451_me143uf5h6.pdf)

## 四、“持牌渠道免费实时行情”该怎样理解

交易所许可单位公示可以用来核验某券商、行情软件商或财经平台是否持有相应展示许可。即使服务商持牌，个人开发者仍需核对自己得到的具体权利：

1. **终端展示**：只允许登录指定 App、桌面软件或网页查看，通常不允许自动批量拉取。
2. **开发/测试用户**：可能由持牌服务商提供 SDK、专线、测试账户或沙箱；这是一项合同权利，不等同于免费公开 API。
3. **非展示自用**：用于内部模型、风控、量化系统等，往往单独许可、限定主体和机房。
4. **接口转发/再分发**：把行情以 API、WebSocket、文件或数据库形式供第三方使用，需单独许可并计费，不能由展示许可推导出来。

个人若只做自用原型，可以选择某些商业平台的免费层或非官方抓取源进行开发测试，但不能把它描述为交易所官方免费实时 API；若要上线给用户、形成 SaaS/数据产品或用于交易生产环境，应向交易所许可单位购买明确涵盖“非展示自用”或“接口转发”的服务，并保留合同、授权范围、终端/用户统计及数据来源记录。

## 五、对最终选型报告的建议分层

- **官方真实时、合规生产级**：交易所/交易所信息公司直连或持牌信息商转售；有明确实时等级、接口文档与 SLA，但收费且主体/场地/用途受限。
- **持牌渠道免费展示**：券商和行情产品的免费 Level-1 终端；适合人看盘，不应列为“免费 API”。
- **官方延迟数据**：深交所明确有 15 分钟延迟层，但是否免费、交付接口与客户资格需询价；目前证据不足以列入“真免费可注册”。
- **个人开发测试**：需转向商业数据平台免费层或非官方源，并在综合报告中单列稳定性、反爬、条款和再分发风险。

## 证据边界

- 本结论基于 2026-08-01 可访问的官方产品页、许可规则和价目表；具体合同价格、优惠及申请口径可能调整，应在采购前向官方或许可商书面确认。
- “没有查到免费个人 API”是对三所官方公开产品与规则的结论，不排除券商阶段性向特定开户客户赠送量化终端或行情权益；这种权益仍受券商协议和交易所授权约束。
- 公开接口规范只说明数据格式，不构成接入权或数据许可；能下载规范也不等于能免费连上生产行情源。
