# Alpha Studio 0.1.3

## 修复和调整

- 报告任务的模型请求可以携带 20 MiB 的历史与预览图片，修复默认 2 MiB 限制导致的 HTTP 413。超限时显示中文提示，并保留已有文件的工具记录。
- 报告封面使用放大的单个品牌 Logo，避免在含文字的 Logo 旁重复品牌名；更新默认图片、报告模板和品牌设置预览。
- 账户与用量页简化为当前按量付费流程，移除订阅额度和订阅账户展示。
- 已完成工具优先显示运行时提供的实际耗时，支持毫秒，避免短操作一律显示为 0 秒。

## 构建和部署

版本号已同步至 npm、Tauri 配置和桌面 Rust 包。macOS Apple Silicon 安装包使用 `make dmg` 构建，生产 API 使用 `make deploy-production` 发布。

发布流程执行完整测试和构建检查，生产部署包含数据库备份、恢复演练、迁移演练、服务切换与冒烟测试。运行时保留数据库备份、旧代码和旧镜像，供应用回滚使用。本版本没有新增数据库迁移。

请求大小修复在部署 API 后生效；品牌、用量页、耗时显示和错误提示在安装新桌面包后生效。
