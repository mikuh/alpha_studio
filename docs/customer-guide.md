# Alpha Studio 客户使用手册

## 1. 安装与激活

1. 从服务人员提供的正式渠道下载安装包；不要运行来源不明的安装包。
2. 首次启动后阅读并勾选软件许可协议、隐私政策、大模型服务方数据传输告知和投资研究风险揭示。
3. 输入订单对应的公司名称和授权码。每台设备占用一个授权名额，设备名称会显示在设备管理中。
4. 激活成功后完成首次使用引导。短期断网时，最近一次在线校验成功后的授权可在有效期内继续使用；超过五天需要联网重新校验。

## 2. 本地数据和大模型服务方

项目目录、持仓、研究资料、会话历史和设置默认保存在当前设备，Alpha Studio 业务服务端不保存这些内容。你主动发起模型调用时，为完成请求所需的对话、附件和上下文会发送给所选大模型服务方。

发送前请检查内容，删除不必要的个人信息、证券账户信息、商业秘密和无权对外提供的材料。大模型服务方可能按照其自身协议处理或保留请求。

## 3. 模型账号

- 使用你自己的大模型服务账号，并通过大模型服务方的官方页面登录。
- 不要向服务人员提供密码、动态验证码、Cookie、Session Token、恢复码或本地 `auth.json`。
- Alpha Studio 不提供共享账号池。后台如登记账号，只用于确认客户被允许使用的账号身份；实际登录仍由账号本人完成。
- 登录异常时先退出模型账号并通过官方页面重新登录，不要反复把验证码发送给任何人。

## 4. 创建项目和备份

为每个项目选择独立的本地工作目录。开始重要研究前确认目录已经纳入 Time Machine、企业备份或其他可靠备份方案。应用升级通常保留本地数据，但升级前仍应备份；卸载应用不一定删除所有本地文件。

## 5. 费用和用量

Alpha Studio 客户端和后台都不提供在线支付、自动扣款或在线退款。一次性软件费和 Token 消耗费在线下结算：

- 后台仅登记已经在线下实际收到的款项和凭证号；
- 模型用量根据已确认的 Token 和价格写入账本；
- 模型调用前的额度预留在结算时释放或扣除，这不是支付或退款；
- 线下收款登记错误时只生成更正流水，不会向客户账户发起退款；
- 对账有疑问时提供时间、模型、账单记录和 request_id 联系服务人员。

## 6. 设备变更和故障恢复

设备遗失、转让或人员离职时，由管理员在设备管理中撤销对应设备，并同时退出大模型服务账号。遇到“授权已失效”时先恢复网络并重新打开应用；仍无法恢复时提供公司名称、设备名称、错误文字和 request_id，切勿发送账号密码或动态验证码。

## 7. AI 与投资研究

模型输出可能错误、遗漏、过时或存在偏差。软件不会自动替你完成证券交易，也不承诺投资收益。涉及具体证券、价格、财务数据、合规判断和交易决策的内容必须由你独立核验。
