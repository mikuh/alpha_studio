# 客户端生命周期测试矩阵

自动化测试 `npm run test:lifecycle` 覆盖首次安装未激活、激活后重启、旧版本会话升级兼容、短期断网、五天校验过期、联网恢复和清除授权。

每个候选版本还必须在受支持的 macOS 与 Windows 真机执行：

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 首次安装 | 全新系统安装并启动 | 只显示激活与协议，不产生可用会话 |
| 正常激活 | 同意协议并输入有效授权码 | 进入工作台，重启后仍有效 |
| 覆盖升级 | 保留本地数据安装新版本 | 项目、会话、设备授权和设置均保留 |
| 短期断网 | 最近校验成功后断网重启 | 在本地授权有效期内可使用本地功能，并明确提示云功能状态 |
| 授权过期 | 将测试授权推进到五天校验边界后断网 | 阻止需要企业授权的功能，不清除本地业务数据 |
| 联网恢复 | 恢复网络并重新校验 | 无需重新安装，刷新令牌后恢复使用 |
| 设备撤销 | 后台撤销当前设备后联网 | 客户端退出授权态，保留本地文件并提示重新激活 |
| 卸载重装 | 卸载应用后重新安装 | 按平台说明正确区分应用文件和用户本地数据 |

测试记录应包含系统版本、芯片/架构、应用版本、结果、截图、日志 request_id 和执行人。
