# Alpha Studio 软件许可及用户服务协议

版本：2026-08-04

欢迎使用 Alpha Studio。本协议由您与向您出具订单、授权码或软件授权文件的 Alpha Studio 服务提供方订立。请在激活前完整阅读；点击同意并激活，即表示您已理解并接受本协议。

## 1. 服务内容

Alpha Studio 是在用户设备上运行的 AI 工作台。主要功能包括本地项目与研究资料管理、大模型服务调用、设备授权、模型用量计费，以及订单约定的其他功能。

具体功能、可用模型、设备数量、授权期限和服务范围，以实际安装版本、订单及授权信息为准。服务提供方可以为了安全、合规、兼容性或产品改进发布更新，并会在重大变化时另行提示。

## 2. 软件费与 Token 消耗费

- 一次性软件费对应订单约定版本和范围的软件使用权，不包含大模型服务方的 Token 消耗。
- Token 消耗费按照调用前展示或订单约定的模型价格、实际可确认的用量和计费规则结算。不同模型的价格可能不同。
- 模型调用前只检查账户余额是否大于 0，不冻结或预扣余额。调用完成后按可确认的实际 Token 用量结算；余额小于等于 0 时，后续按量调用将被拒绝。
- 本系统不提供在线支付、自动扣款或在线退款功能。一次性软件费和 Token 消耗费均在线下按照订单或对账结果结算，后台只登记已经收到的线下款项；登记错误时生成不可篡改的更正流水，不会向客户账户发起退款。
- 服务提供方不会以推荐股票的数量、策略收益或投资结果收取费用，也不参与用户投资收益分成。
- 软件费相关争议、解除和款项返还（如适用）均按线下订单、双方约定及适用法律处理，不通过本系统自动执行。因服务提供方原因持续无法激活或无法提供订单约定的核心功能时，您可以申请修复、更换或按线下订单约定处理。

## 3. 账号与设备授权

- 每个大模型服务账号应由对应的真实用户本人使用。您应通过大模型服务方提供的官方登录流程登录，并自行保管密码、多因素认证、恢复方式、会话令牌和本地授权文件。
- Alpha Studio 不要求您向服务提供方提交大模型服务账号密码、MFA、Cookie、Session Token 或 `auth.json`。
- 授权码、可激活设备数量和设备管理权限以订单及后台记录为准。不得出售、出租、共享授权码或绕过设备限制。
- 设备遗失、转让或离职交接时，应及时撤销设备授权及大模型服务账号的登录状态。

## 4. 用户数据与大模型服务方

项目文件、持仓、研究记录和会话历史默认保存在您的本地设备。只有在您发起模型调用时，为完成请求所需的会话内容、您选择的附件或上下文才会发送给您选择的大模型服务方；具体规则见《隐私政策》和《大模型服务方数据传输告知与同意》。

## 5. 使用规范

您不得利用本软件从事违法活动、侵犯他人权益、绕过模型供应商限制、共享第三方账号，或未经授权对外转售行情、模型和软件访问能力。您应确保提交给模型的内容具有合法来源和必要授权。

## 6. AI 与投资研究风险

模型输出可能错误、遗漏、过时或带有偏差。Alpha Studio 不承诺投资收益，不保证研究结论准确，也不会自动替您完成证券交易。任何涉及具体证券的内容均须由具备相应能力和责任的人员独立核验；详细风险见《AI 与投资研究风险揭示书》。

## 7. 服务可用性与责任边界

大模型服务方、网络、操作系统和数据源可能发生中断或变化。服务提供方会在合理范围内修复自身软件问题，但不对外部服务的持续可用性作绝对保证。任何责任限制均不排除适用法律规定不得限制或排除的责任。

## 8. 协议变更、终止与联系

协议发生涉及收费、数据用途或用户核心权利的重大变化时，客户端会要求您重新确认。您停止使用并撤销设备授权后，可以按照隐私政策申请处理必要的服务端记录。

客服、投诉和争议处理渠道以订单、授权文件或产品内公布的信息为准。
