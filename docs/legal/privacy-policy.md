# Alpha Studio 隐私政策

版本：2026-08-04

本政策说明 Alpha Studio 如何处理与软件激活、设备授权、模型调用和计费有关的信息。Alpha Studio 采用“业务数据本地优先”的设计，但为了完成授权与计费，服务端仍会处理少量必要元数据。

## 1. 默认保存在本地的数据

以下数据默认保存在您的设备，不上传至 Alpha Studio 业务数据库：

- 本地项目文件和工作目录；
- 持仓、交易记录和研究资料；
- 会话历史、研究报告、自动化任务及本地配置；
- 您未主动选入模型上下文的文件和内容。

您负责本地设备、系统账号和备份的安全。卸载软件不一定自动删除全部本地文件，请在交接或处置设备前自行清理。

## 2. 激活和计费所需的服务端元数据

为了验证授权、限制设备数量、提供模型目录和完成计费，服务端会处理：

- 客户或企业名称、内部租户及用户标识；
- 设备名称、随机设备指纹、设备授权状态和最近校验时间；
- 授权码的加密或摘要信息及使用状态；
- 调用的模型、Token 数量、调用状态、时间、费用和必要的审计记录；
- 协议版本及同意时间。

这些信息不包含会话正文、持仓明细或本地研究报告。服务提供方不会将上述信息用于广告画像，也不会用您的会话内容训练 Alpha Studio 自有模型。

## 3. 发送给大模型服务方的数据

当您主动发起模型调用时，请求内容会发送给所选大模型服务方。内容可能包括：

- 您输入的文字；
- 您主动附加或选择的文件、图片和上下文；
- 为保持当前会话连贯所必需的相关历史消息；
- 模型调用所需的技术参数。

在网关模式下，Alpha Studio 服务端可能瞬时转发请求，但不以产品功能为目的把会话正文持久化到业务数据库。大模型服务方可能依据其自身协议、隐私政策和安全规则处理或保留数据。

请勿提交无权处理的个人信息、商业秘密或其他敏感内容。涉及个人持仓、交易记录、金融账户或身份信息时，请先确认具有合法处理依据。

## 4. 处理目的与最小必要原则

服务端元数据仅用于软件激活、设备管理、用量计费、安全审计、故障排查、争议处理和履行适用法律义务。我们将把访问权限限制在履行上述目的所必需的范围。

## 5. 保存期限

设备授权信息在授权有效期间保存；授权结束后，将在线下款项核对、账单争议、安全事件和法定义务所需的最短期间内保存，之后删除或匿名化。会话正文不作为 Alpha Studio 云端业务记录长期保存。

## 6. 信息共享与跨境

除完成您主动选择的大模型服务调用、基础设施受托处理、履行法律义务或保护安全所必需外，服务提供方不会出售您的个人信息。

如果您选择的大模型服务方位于境外或从境外处理数据，相关会话内容可能发生跨境传输。请在发送前阅读《大模型服务方数据传输告知与同意》及对应服务方规则；不同意时请勿选择该模型或发送相关内容。

## 7. 您的权利

您可以通过订单、授权文件或产品内公布的客服渠道，请求查询、更正、删除必要的服务端元数据，撤销设备授权，或对计费及数据处理提出投诉。部分账单、安全审计或法定记录可能需要在必要期限内继续保存。

## 8. 安全事件与政策更新

如发生可能影响您权益的数据安全事件，服务提供方将依适用法律采取补救和通知措施。处理目的、数据类型、第三方接收方或用户权利发生重大变化时，将提示您阅读并重新确认更新后的政策。
