# 大模型服务方数据传输告知与同意

版本：2026-08-04

Alpha Studio 本身不在云端长期保存您的会话正文，但您选择使用大模型服务方提供的服务时，完成请求所需的内容必须传输给对应服务方。

## 1. 接收方与处理内容

实际接收方取决于您在模型选择器中选择的模型和账号。可能发送的内容包括当前提示词、为保持上下文所需的历史消息、您主动选择的附件或文件内容，以及模型调用参数。

Alpha Studio 不会主动上传未被当前请求引用的本地项目、持仓、研究记录或其他文件。

## 2. 处理目的

大模型服务仅在您发起请求时被调用，目的是生成您要求的文本、分析、代码或其他结果。Alpha Studio 可能通过网关瞬时转发请求并记录模型名称、Token 数量、状态、时间和费用，但不会把会话正文写入 Alpha Studio 业务数据库。

## 3. 第三方规则和可能的跨境处理

大模型服务方将依据其服务条款、隐私政策、数据保留和安全规则处理内容。部分模型或处理设施可能位于中国境外，因此您发送的内容可能发生跨境传输。

您应在模型选择和发送前确认接收方、适用地区及其规则。若您不同意某一提供商的数据处理方式，请不要选择该模型；可以改用符合您要求的其他模型或完全在本地完成工作。

## 4. 敏感内容提示

请勿发送无权披露的个人信息、客户资料、未公开证券信息、商业秘密、账号密码或金融账户信息。确需发送个人信息时，您应确保已取得合法处理依据和必要授权，并只提供完成任务所需的最少内容。

## 5. 同意范围

勾选同意表示您理解：只有在您主动发起调用时，相关内容才会被发送给您选择的大模型服务方。此确认不代表您必须使用所有模型，也不替代特定境外接收方依法可能需要的额外告知或单独同意。
