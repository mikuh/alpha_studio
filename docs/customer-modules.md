# 客户模块权限

在管理后台进入 **客户 → 编辑 → 模块权限**，分别勾选“侧边功能”和“快捷卡片”，点击“保存客户”。新建客户也可直接配置。支持按组全选、清空；客户列表显示已开通数量。

- 侧边功能：AI 同事、文件、投研工作台、浏览器。
- 快捷卡片：生成今日报告、产业主线早报、盘中监控、晚间复盘、核验研究证据、公司 Thesis、研究校准、挖掘量化因子。

授权绑定客户，适用于该客户的所有设备。客户激活、启动、窗口重新获得焦点和约每分钟续租时同步。未授权的入口不显示，已撤权的面板会关闭。没有开通模块的客户仍可使用基础对话。模块权限与 GPT 套餐、机器数、计费模式独立。

快捷卡片同时管理对应官方技能的使用权限，技能列表、手动输入技能名、历史重发、排队消息和自动化执行遵循同一授权。执行受保护任务时必须连通后台进行校验；离线时不能启动新的模块任务。撤权阻止后续操作，不主动中止已开始的模型任务。已生成的本地研究资料继续保留。

首次上线需先运行数据库迁移 `0026_tenant_module_permissions.sql`，再部署后台、管理端并更新桌面客户端。**已有客户和新客户默认均不开通任何模块**，管理员需要逐客户勾选；升级前应安排好现有客户的授权。旧客户端没有界面过滤，必须升级客户端才能完整启用这套规则。

## 实现与验证

`shared/productModules.json` 是模块 ID、名称、技能对应关系与共享行情能力的统一目录。客户表的 `enabled_modules` 为默认空数组；只有管理员接口可以修改。省略字段的旧版管理员更新保留原权限，显式空数组撤销全部权限，未知 ID 拒绝保存。

`POST /api/client/modules/authorize` 验证设备身份、客户状态和数据库中的实时权限。激活、续租、客户列表及账单摘要均返回 `tenant.enabledModules`。行情接口根据使用行情的模块校验授权，SSE 每次推送前再次校验。日报与盘中监控可独立获取所需行情，无需额外开通投研工作台。

桌面运行层在任务启动和引导消息时校验权限，并从应用维护的运行目录移除未授权的官方技能和 AI 同事定义。该机制控制应用提供的模块，不删除客户文件或限制客户自行编写普通提示词开展研究。

真实数据库集成测试可针对隔离数据库执行：

```sh
ALPHA_MODULE_TEST_DATABASE_URL=postgres://postgres@127.0.0.1:15439/alpha_modules_test \
  cargo test --manifest-path backend/Cargo.toml --test routes tenant_module_permissions_lifecycle -- --ignored
```
