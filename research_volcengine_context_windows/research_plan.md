# 火山方舟模型上下文窗口核验计划

## 主要问题

确认 Alpha Studio 当前使用的 GLM-5.2 与 DeepSeek V4 Flash 在火山方舟上的实际模型标识、上下文窗口、最大输出及相关计费，并据此修复输入预算预检和上下文压缩策略。

## 子课题

1. GLM：查找火山方舟官方模型列表、规格与定价，确认 GLM-5.2 对应的方舟模型标识和上下文窗口。
2. DeepSeek：查找火山方舟官方模型列表、规格与定价，确认 DeepSeek V4 Flash 对应的方舟模型标识和上下文窗口。
3. 本地链路：定位 `per-run safety limit` 与重复压缩的触发代码，核对模型元数据从管理端到 Codex CLI 的传递。

## 综合方式

只以火山引擎/火山方舟官方文档为模型规格依据；若界面名称是内部别名，则通过实际 `upstream_model` 映射到官方模型。最终把经过核验的窗口、输出预留和价格转换成显式模型元数据与动态单次运行安全预算，并用单元/集成测试覆盖。
