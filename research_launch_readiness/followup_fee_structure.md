# 一次性软件费、Token 消耗费与荐股软件“经济利益”要件

**核查日期：2026-08-04**  
**来源限制：仅使用中国证监会及派出机构官方规则、行政处罚、行政复议和官方案例。**  
**具体问题：Alpha Studio 只收一次性软件费和 Token 消耗费，不对推荐股票或策略单独收费，是否因此不满足“直接或者间接获取经济利益”？**

## 一、直接结论

**不能据此排除。**

《荐股软件暂行规定》并不要求经营者为每条股票推荐、每个策略或每次回答单独定价。它规定的是：向投资者**销售或者提供荐股软件**，并直接或者间接获取经济利益，即属于证券投资咨询业务。[证监会第 40 号公告及附件](https://www.csrc.gov.cn/csrc/c101838/c1021995/content.shtml)、[证监会官方修订文件 PDF，第 152—155 页](https://www.csrc.gov.cn/csrc/c101950/c1048010/1048010/files/%E9%99%84%E4%BB%B61%EF%BC%9A%E3%80%8A%E5%85%B3%E4%BA%8E%E4%BF%AE%E6%94%B9%E9%83%A8%E5%88%86%E8%AF%81%E5%88%B8%E6%9C%9F%E8%A7%84%E8%8C%83%E6%80%A7%E6%96%87%E4%BB%B6%E7%9A%84%E5%86%B3%E5%AE%9A%E3%80%8B.pdf)

如果客户支付一次性软件费后获得包含具体证券分析、品种选择或买卖时机建议的 Alpha 版本，这在文义上就是“销售荐股软件并获取经济利益”的高风险事实。把证券建议标为免费附送、把价格统一写成“软件许可费”，或不为具体建议设置单独 SKU，并没有出现在官方规则的排除条款中。

Token 消耗费是否精确按上游成本转付、完全不加价，现有官方材料没有给出直接答案。但这也不能消除已经存在的一次性软件销售收入；而且“无毛利/仅覆盖成本”不是证监会已经公布的经济利益安全港。

因此，当前最稳妥的判断是：

- **一次性软件费：**很可能已经独立满足直接或间接经济利益关联，不需要另收“荐股费”。
- **按量 Token 费：**若与生成具体证券建议的调用绑定，会进一步增强有偿服务关联；零加价只可能影响事实评价，不能当然免责。
- **真正排除风险的关键：**不是改收费名称或拆分价格，而是从收费版本中移除/禁用具体证券分析、选择和买卖时机建议功能，或由持牌主体实质经营。

以上第一、二点包含基于规则与案例的推断；证监会尚未就“通用 LLM 软件费 + 原价 Token 转付”发布专项解释，正式上线仍需中国证券律师确认。

## 二、明确规则与官方案例

### 1. 规则要求“销售或提供 + 直接或间接经济利益”，不要求推荐单独计价

《关于加强对利用“荐股软件”从事证券投资咨询业务监管的暂行规定》明确：

- 软件只要具备具体证券投资分析/价格预测、证券品种选择、买卖时机或其他证券投资分析预测建议功能，即落入“荐股软件”定义；
- 只具备证券信息汇总或历史数据统计、且不具备上述功能的软件不属于荐股软件；
- 向投资者销售或提供荐股软件，并直接或间接获取经济利益，属于证券投资咨询业务，须取得资格。

规则没有要求：推荐必须单独标价、收费必须按推荐次数计算、荐股必须是价格表中的唯一或主要项目，也没有“按成本收取技术费”或“无加价”例外。[证监会有关部门负责人对规则的官方说明](https://www.csrc.gov.cn/csrc/c100028/c1002385/content.shtml)

### 2. 月费、年费形式的软件订阅被直接作为有偿荐股事实

深圳证监局 2023 年防非案例记载，某公司把大数据选股策略包装成网站、APP、微信公众号服务产品，按月或按年向投资者收取订阅服务费，付费后接收荐股提示。因产品提供具体证券选择或买卖时机建议，官方将其概括为非法销售荐股软件并从事证券投资咨询。[深圳证监局 2023 年防非宣传案例汇编](https://www.csrc.gov.cn/shenzhen/c105615/c7462141/content.shtml)

这说明“订阅服务费”本身即可成为销售/提供荐股软件并获取利益的收费形式，无需为每只股票或每条建议单独收费。

### 3. 软件销售收入被整体认定，成本支出通常不能把收费变成无偿

深圳云财经行政处罚案中，网站、APP 和微信公众号中的多款软件向客户提供具体证券选择或买卖时机建议。公司未取得资格，对外销售这些软件，共获得收入 548.6 万余元。

当事人主张违法所得应按“获利金额”计算，并扣除相关成本、税费和退款。深圳证监局明确：扣除非法经营期间相关成本和税费没有法律依据；对有证据证明的退款才予扣除。最终没收违法所得并处同额罚款。[深圳证监局行政处罚决定书〔2023〕4号](https://www.csrc.gov.cn/shenzhen/c104320/c7419426/content.shtml)

这个案例直接处理的是违法所得计算，不是专门解释“零加价 Token 转付”的经济利益要件。因此不能把它扩大为“任何成本转付都必然属于经济利益”。但它至少明确否定了“收入扣除经营成本后利润较少/没有利润，所以有偿性质或违法收入应按净利润理解”的一般抗辩路径。

### 4. 软件购买价、销售收入和分成属于荐股软件完整经营链路

上海聿莜案中，证监会认定 Alpha 系列、锦囊系列等软件及其基础/辅助产品因能提供具体证券分析意见和买卖时机建议而属于荐股软件。客户销售款进入持牌机构指定账户，荐股软件销售收入再按约定比例分配；监管以相关销售收入为基础认定违法所得。该案处罚的直接违法点是持牌机构把销售业务委托给无资格代理人，但其事实部分清楚地把软件成交价、销售收入和收入分成视为荐股软件经营活动。[证监会行政处罚决定书〔2020〕104号（上海聿莜）](https://www.csrc.gov.cn/csrc/c101928/c1416722/content.shtml)

这进一步说明，“软件产品销售款”不是与投顾经济利益无关的中性名称；如果购买的软件本身具有规则定义的荐股功能，软件价款与该业务存在直接联系。

### 5. 知识付费、会员费以及部分内容免费，不会自动切断整体有偿关系

易伟案中，当事人用微博公开证券投资建议招募会员，之后通过每周邮件、微信私信和朋友圈向付费会员提供对上市公司和股票的看法、具体买入时点、买入价格及操作建议，收取会员费。

当事人主张：邮件内容只是“知识付费”；微博、微信、朋友圈内容没有单独收费；个别交流也不是履行会员合同。证监会从公开引流、会员招募、定期邮件和私域服务的**整体经营活动**判断，认定构成直接或间接有偿证券投资咨询。[证监会行政处罚决定书〔2023〕5号（易伟）](https://www.csrc.gov.cn/csrc/c101928/c7183832/content.shtml)

行政复议决定进一步明确：是否对某一单项活动直接收费、当事人本人是否认为属于证券投资咨询，不影响根据全部客观行为进行定性；复议维持原处罚。[证监会行政复议决定书〔2023〕117号](https://www.csrc.gov.cn/csrc/c105938/c869eb4dfb2244e109d753cb548b31dca/content.shtml)

该案不是软件或 Token 计费案，但它对 Alpha 的反驳力很强：不能因为具体股票回答没有单独价格，就把收费软件中的该部分当然视为与经济利益无关的免费内容。

## 三、对 Alpha Studio 收费结构的合理推断

以下判断是把上述规则和案例应用到 Alpha 的事实，不是证监会对 Alpha 作出的正式认定。

### 1. 一次性软件费不是弱关联，而是最直接的风险事实

如果一次性付费取得的版本内置具体标的建议卡、增配/减配/回避、建议权重、价格区间、买卖触发、持有或退出条件，客户支付的是一个具备荐股功能的软件产品。即使合同、发票和价格表只写“Alpha Studio 软件许可费”，仍很可能被理解为销售荐股软件取得收入。

以下拆分通常不足以改变该实质：

- 宣称软件费只对应安装包、UI、更新或通用工作区，证券功能“免费赠送”；
- 所有功能合并成一个买断价，不对证券模块单列 SKU；
- 把荐股入口改叫“研究”“决策”“候选”或“教育”；
- 软件费只收一次，而不是月费/年费；
- 推荐由客户主动点击或提问生成，不主动推送。

官方规则没有要求经常性收费或主动推送；深圳云财经和易伟案也体现了实质及整体经营链路优先于收费/内容标签。

### 2. Token 费即使零加价，也不存在已确认的安全港

可作以下分层判断：

- **Alpha 对 Token 加价或收平台服务费：**与生成证券建议的次数或用量直接联动，经济利益关联最强。
- **Alpha 代收后按上游账单原价转付：**没有找到证监会官方材料明确说这当然不属于直接或间接经济利益。代收使客户能够持续使用建议功能，Alpha 也因此避免自行承担推理成本；但“避免成本是否构成经济利益”、真正代收而非收入的会计/合同条件，仍属未知边界。
- **客户直接向模型商付费（BYOK），Alpha 不经手 Token 款：**Token 这一项与 Alpha 的收入联系会降低，但一次性软件费与内置荐股功能的联系仍然存在。
- **Alpha 免费承担全部 Token 成本：**也不会抹去一次性软件销售收入；反而可能被看成付费软件所包含的服务成本。

因此，讨论 Token 是否加价只有在“一次性收费版本本身不再具备荐股功能”之后才可能成为次要边界问题。对当前结构，它不是决定性抗辩。

### 3. “股票功能使用率很低”或“用户买的是通用功能”仍不足以形成确定豁免

《荐股软件暂行规定》使用“具备”相关功能，而非“主要收入来自”或“多数客户实际使用”。如果商业安装包保留稳定可调用的证券建议工作流，即使客户主要购买编码、写作或模型网关能力，仍存在软件整体被认定具备荐股功能的风险。

真正降低关联的事实应包括：从收费通用版删除证券专用提示/Skill、建议卡、持仓决策和快捷任务；对具体证券分析、选择及买卖时机建议设置技术拒答；销售、演示和客户支持均不推广这类用途。仅在合同内把价格分配给“通用功能”不够。

## 四、收费场景对比

| 场景 | 官方材料支持程度 | 对“经济利益”要件的判断 |
|---|---|---|
| 按月/按年付费后接收具体选股或买卖时机提示 | 深圳证监局官方案例直接覆盖 | 明确高风险，属于典型有偿荐股软件 |
| 购买一次性软件后获得内置具体证券建议功能 | 规则文义为“销售荐股软件”；上海聿莜、深圳云财经均按软件销售收入观察 | 高风险；无须每条建议另收费 |
| 会员费/知识付费，公开建议免费、付费区另有服务 | 易伟处罚和复议直接覆盖整体经营链路 | 明确不能仅凭单项内容免费排除有偿咨询 |
| 证券功能免费赠送，但整个软件收费 | 未找到完全同构案例；规则含“间接经济利益”，易伟案支持整体判断 | 高风险合理推断，不是官方明示结论 |
| Token 按量加价 | 未找到 LLM 专项案例 | 很可能构成与建议调用直接关联的收入 |
| Token 精确按成本代收转付、零加价 | 未找到官方专项口径 | 未知；不存在已确认安全港，且软件费仍独立存在 |
| 客户 BYOK 并直接付模型商，Alpha 不经手 Token 款 | 未找到官方专项口径 | 仅降低 Token 收费关联，不消除付费软件本身的风险 |
| 完全免费、无广告/引流/数据变现/付费升级或其他利益 | 规则要求直接或间接经济利益，但未找到通用 LLM 免费服务案例 | 可能削弱《荐股软件暂行规定》第二条要件；仍须确认其他证券咨询及网上信息规则，不可视为普遍安全港 |

## 五、官方尚未明确的边界

本轮没有找到证监会或证监局对以下新型 LLM 收费事实的正式解释或处罚案例：

1. **Token 原价转付。** 真正按上游账单逐笔代收、无加价、款项会计上不确认收入时，是否仍属“间接获取经济利益”。
2. **一次性通用软件买断价的功能分配。** 同一软件同时提供编码、写作和证券功能，如何判断软件费与证券功能的对价联系；收入占比是否有意义。
3. **极低频、用户自发的证券回答。** 收费通用软件删除所有证券专用入口后，偶发越狱回答是否足以认定软件“具备”荐股功能。
4. **B2B 企业采购。** 客户是企业而非自然人投资者时，软件最终使用者、服务对象及“向投资者销售或提供”如何认定。
5. **客户自建证券 Skill。** Alpha 不提供或分发提示，客户自行创建且只在本地运行时，软件费与该客户内容的关系。
6. **成本和经济利益的区分。** 深圳云财经案拒绝从违法所得扣除经营成本，但未回答完全无毛利代收在行为定性阶段是否构成经济利益。

这些事项必须由证券律师结合合同、发票、资金流、会计确认、真实产品功能、销售话术和客户使用路径出具书面意见；不能仅凭“无单独荐股收费”自行归入豁免。

## 六、对上线决策的建议

若 Alpha 未采用持牌投顾经营结构，收费方案本身不能解决当前功能风险。建议：

1. **无牌通用版**：从一次性收费安装包和远程 Skill 中删除/禁用具体证券分析、选择、价格预测、买卖时机、仓位及持有退出建议，只保留事实信息汇总和历史数据统计，并对具体投资建议拒答。
2. **收费隔离不是功能隔离**：不要依赖“证券功能不单独收费”“Token 无加价”“免费赠送”作为上线依据。
3. **持牌版**：若保留现有证券建议工作流，应由持牌主体实质控制产品、签约收费、人员、适当性、审核、风险揭示、回访投诉和留痕；Alpha 的软件费、Token 费与持牌服务费如何收取和分配仍需专项法律设计。
4. **保存证据**：上线前形成版本级功能清单、收费及资金流图、Token 结算规则、上游账单、收入确认政策、销售材料和输出样本，供律师按真实业务而非合同名称审查。

一句话结论：**只收一次性软件费和 Token 消耗费，不对每条股票建议另收费，仍很可能满足“直接或者间接获取经济利益”；零加价 Token 转付目前属于未明确边界，不能覆盖或抵消一次性软件销售收入。**
