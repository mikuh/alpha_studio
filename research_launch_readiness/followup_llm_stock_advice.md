# 通用 LLM 股票问答与 Alpha Studio 荐股软件边界

**核查日期：2026-08-04**  
**来源限制：仅使用中国证监会及派出机构官方材料。**  
**目的：回应“豆包、DeepSeek 等通用 LLM 也能回答股票问题，为何 Alpha Studio 风险更高”的问题。本文不构成法律意见。**

## 一、直接结论

“通用 LLM 潜在能够回答股票问题”与“经营者把具体证券建议做成面向投资者的付费产品功能”不是同一个事实状态。

证监会规则的核心要素是：

1. 软件产品、软件工具或终端设备**具备并对外提供**涉及具体证券的分析/价格预测、证券品种选择、买卖时机或其他投资分析预测建议功能；
2. 经营者向投资者销售或提供该软件；
3. 经营者直接或间接获取经济利益。

这些要素成立时，规则明确把业务认定为证券投资咨询，须取得相应资格。[证监会第 40 号公告及附件](https://www.csrc.gov.cn/csrc/c101838/c1021995/content.shtml)、[证监会现行修订文件 PDF，第 152—155 页](https://www.csrc.gov.cn/csrc/c101950/c1048010/1048010/files/%E9%99%84%E4%BB%B61%EF%BC%9A%E3%80%8A%E5%85%B3%E4%BA%8E%E4%BF%AE%E6%94%B9%E9%83%A8%E5%88%86%E8%AF%81%E5%88%B8%E6%9C%9F%E8%A7%84%E8%8C%83%E6%80%A7%E6%96%87%E4%BB%B6%E7%9A%84%E5%86%B3%E5%AE%9A%E3%80%8B.pdf)

规则**没有**公布“通用大模型例外”“用户主动提问例外”或“AI 自动生成例外”。因此不能得出“其他通用模型会答，所以 Alpha 一定合法”；同样，也不能仅凭一个通用模型理论上可被诱导回答股票问题，就断言其所有通用服务必然属于荐股软件。后者需要结合实际产品功能、默认工作流、目标用户、营销、收费和持续运营事实判断。

对 Alpha Studio 而言，风险差异不在底层模型是豆包、DeepSeek 还是其他 LLM，而在 Alpha 已把具体股票、建议动作、建议权重、价格区间、触发/退出条件和“确认建议”做成固定产品结构。这个事实比“空白聊天框偶尔可能回答股票问题”更接近证监会规则及处罚案例中的软件产品化荐股。

## 二、明确规则

### 1. 监管定义看具体证券咨询功能，不看算法名称

《关于加强对利用“荐股软件”从事证券投资咨询业务监管的暂行规定》将下列任一项列为荐股软件功能：

- 涉及具体证券投资品种的投资分析意见或价格走势预测；
- 具体证券投资品种选择建议；
- 具体证券投资品种买卖时机建议；
- 其他证券投资分析、预测或者建议。

规则同时明确：只具备证券信息汇总或证券品种历史数据统计功能，且不具备上述建议功能的软件，不属于“荐股软件”。向投资者销售或提供荐股软件并直接或间接获利，则属于证券投资咨询业务，须经证监会许可。[证监会官方规则全文所在修订文件 PDF，第 152—155 页](https://www.csrc.gov.cn/csrc/c101950/c1048010/1048010/files/%E9%99%84%E4%BB%B61%EF%BC%9A%E3%80%8A%E5%85%B3%E4%BA%8E%E4%BF%AE%E6%94%B9%E9%83%A8%E5%88%86%E8%AF%81%E5%88%B8%E6%9C%9F%E8%A7%84%E8%8C%83%E6%80%A7%E6%96%87%E4%BB%B6%E7%9A%84%E5%86%B3%E5%AE%9A%E3%80%8B.pdf)

该定义使用“软件产品、软件工具或者终端设备”，没有按确定性算法、统计模型或生成式 AI 区分。因此，“结论由 LLM 生成”本身不是规则列明的排除条件。

### 2. 监管执法重视实际功能，不接受换名后的形式抗辩

深圳证监局 2023 年处罚决定认定，网站、APP、微信公众号中的多款软件向客户提供具体证券选择或买卖时机建议，属于荐股软件。涉案方抗辩称软件只是提醒哪些股票符合特定条件、属于量化数据统计软件，监管仍根据产品实际能向客户提供具体证券选择/时机建议认定违法，并没收违法所得 548.6 万余元、处同额罚款。[深圳证监局行政处罚决定书〔2023〕4号](https://www.csrc.gov.cn/shenzhen/c104320/c7419426/content.shtml)

深圳证监局发布的防非案例还概括了同一案件的经营特征：自研“大数据选股策略”，通过网站、APP、微信公众号包装成服务产品，按月或按年收取订阅费，付费后向投资者发送荐股提示。[深圳证监局 2023 年防非宣传案例汇编](https://www.csrc.gov.cn/shenzhen/c105615/c7462141/content.shtml)

这两份官方材料至少说明：

- “量化统计”“提醒符合条件”不当然排除具体证券选择建议属性；
- 网站、APP、公众号或其他软件载体不是关键区别；
- 订阅软件费可以成为对外销售并获取经济利益的事实；
- 监管可以根据软件实际功能定性，并不要求经营者在产品中直接使用“荐股”名称。

### 3. 外层名称不能覆盖服务实质

证监会风险警示明确指出，有机构表面以“投资者教育”名义销售课程，但实际包含分析预测行情、推荐股票及指导买卖点，仍属于应选择持牌机构提供的证券投资咨询服务。[证监会《警惕以“投资者教育”为名的非法荐股活动》](https://www.csrc.gov.cn/csrc/c106299/c1600729/content.shtml)

因此，“研究”“教育”“候选”“仅供参考”等称谓不是监管安全港；判断仍应回到是否实际提供具体证券分析、选择或买卖时机建议。

证监会 2023 年易伟案进一步表明，不能孤立看某一条内容是否收费。当事人用微博公开投资建议招募会员，再以邮件、微信和朋友圈向付费会员提供具体买入时点、价格及操作建议；其以“知识付费”、部分公开内容未单独收费进行抗辩，证监会仍按整套经营活动认定为直接或间接有偿证券投资咨询，行政复议维持了该认定。[证监会行政处罚决定书〔2023〕5号（易伟）](https://www.csrc.gov.cn/csrc/c101928/c7183832/content.shtml)、[证监会行政复议决定书〔2023〕117号](https://www.csrc.gov.cn/csrc/c105938/c869eb4dfb2244e109d753cb548b31dca/content.shtml)

### 4. 官方监管口径已把“AI 选股”视为需要识别的高风险包装

以下材料是证监局风险提示，不是为通用大模型制定的独立法律规则，但能说明监管没有把“AI”当作当然例外：

- 深圳证监局 2026 年风险提示列举了借社交平台宣传“大数据智能选股系统”、宣称模型胜率并销售 AI 量化选股软件及配套荐股服务收费的情形。[深圳证监局《AI量化选股不可信，荐股服务需谨慎》](https://www.csrc.gov.cn/shenzhen/c105614/c7645981/content.shtml)
- 江苏证监局 2026 年风险提示重申相关咨询业务须取得资格，并把“AI 选股、大数据诊股、量化交易”包装、精准选股宣传和高价软件/课程收费列为非法金融活动常见形式。[江苏证监局关于虚假炒股软件、“AI炒股”的风险提示](https://www.csrc.gov.cn/jiangsu/c105410/c7612290/content.shtml)

这支持一项谨慎推断：监管关注的是 AI 被如何包装、输出和商业化，而不是因为使用 AI 就降低持牌要求。

## 三、合理推断：为什么通用 LLM 与当前 Alpha 的风险不同

以下不是证监会为 LLM 发布的明文分类，而是依据上述功能规则和执法事实作出的风险推断。

| 比较事实 | 通用 LLM 的典型状态 | 当前 Alpha Studio 的状态 | 风险意义 |
|---|---|---|---|
| 产品目的 | 通用写作、问答、编程等，股票只是无数可能话题之一 | A 股研究和决策工作台是显著产品场景 | 投资者导向和证券业务关联更强 |
| 默认功能 | 空白对话，通常没有内置具体证券决策结构 | 内置具体证券代码/名称、增配/减配/回避、优先级、建议权重、价格区间、触发与失效条件 | 直接对应规则列举的选股及买卖时机建议 |
| 输出形成 | 可能需用户自行构造提示，结果偶发且非标准化 | 模板要求持续生成进攻概率、标的矩阵、入场及退出条件，并可形成“建议卡” | 更像稳定、可重复交付的证券咨询功能 |
| 个性化 | 未必掌握用户持仓和交易记录 | 可基于实盘持仓生成买卖触发和仓位上限 | 更接近向具体客户提供投资建议 |
| 收费关联 | 用户购买的是综合通用能力，股票问答未必是销售重点 | 商业版将证券研究工作流作为客户价值的一部分 | 软件费被视为直接或间接经济利益的风险更高 |
| 运营控制 | 平台未必策划或审核证券建议 | Alpha 编写提示模板、字段、风险复核、确认流程并通过自身网关交付 | Alpha 对证券建议功能的设计和运营联系更强 |

最重要的限定是：**通用性只能作为降低风险的事实之一，不是明文豁免。** 如果某通用 LLM 经营者主动宣传荐股、为投资者制作专门入口、稳定输出具体证券选择/时机建议并据此获利，它也可能出现同类监管问题。其他产品尚未被公开处罚或仍提供类似回答，不是 Alpha 的免责依据。

## 四、哪些事实变化能实质降低 Alpha 的风险

### A. 降低幅度最大：移除产品化证券建议功能

以下变化应同时发生，而不是只改界面文字：

1. 从面向无牌主体客户的版本中删除或技术禁用具体标的推荐/排行、涨跌或“进攻”概率、增配/减配/回避、建议权重、观察价位、入场/买卖触发、持有及退出条件、“确认建议”等结构化功能。
2. 删除默认提示、Skill、日报模板和快捷任务中要求模型产出上述内容的指令；不能仅隐藏页面而保留可由客户一键调用的后台能力。
3. 不把用户持仓、交易记录、自选股与模型结合生成个性化买卖、仓位或止盈止损意见。
4. 对通用聊天增加证券输出边界：允许事实查询、公开信息摘要和历史数据统计；拒绝由 Alpha 形成具体证券分析预测、证券选择或买卖时机建议。

第 4 点与规则唯一明确列出的非荐股软件区间一致，即“证券信息汇总或历史数据统计，且不具备建议功能”。需要注意，按条件筛出具体证券的所谓“中性筛选”仍可能实质成为证券品种选择建议，不能未经法律审查就当作安全功能。

### B. 降低经营关联：改为真正的通用工具

- 产品定位、首页、销售材料、演示、客户成功和定价中不宣传荐股、命中率、收益、股票池、交易信号或“抓主线/龙头”等能力。
- 收费购买的是横跨行业的通用工作区和模型能力，不设置与选股、信号、荐股提醒或投研结论挂钩的套餐、增值包和绩效宣传。
- 不由 Alpha 编辑、审核、推送或定期发布证券建议，不建立证券建议榜单、回测业绩或客户跟随机制。
- 对客户自己在空白通用对话中的提示负责范围、禁止用途及违规处置建立合同和技术控制，并保留能够证明产品没有策划具体证券咨询功能的设计及运营记录。

这些变化会使 Alpha 更接近“通用 LLM/通用工作区可能被用户用于许多问题”的事实，但由于规则没有通用模型安全港，仍需律师确认技术控制是否足够。

### C. 改为持牌机构控制下的技术服务

若证券功能确有商业必要，风险较低的方向不是争论 LLM 与传统软件不同，而是让具备证券投资咨询资格的证券公司或证券投资咨询机构成为真实服务主体，并由其控制客户签约、收费、人员、内容审核、适当性、风险揭示、回访、投诉和留痕。

仅在合同标题写“技术外包”而 Alpha 仍自行定价、招揽投资者、设计并交付建议，不足以证明服务主体已经改变。合作结构须由持牌机构合规部门和证券律师共同确认。

## 五、哪些变化不会消除风险

以下做法单独使用，不能把产品化具体证券建议变成通用模型能力：

- 加“仅供研究/教育/参考，不构成投资建议”免责声明；
- 把“买入/卖出”改名为“候选、增配候选、减配候选、回避”或把荐股模块称为“研究助手”；
- 让用户先输入股票代码、持仓或“请给建议”，再由系统回答；
- 要求用户点击“人工确认”后才显示、保存或执行建议；
- 增加 AI 风险复核、置信度、反对理由或风险提示，但仍输出具体证券选择及买卖时机；
- 强调输出来自通用 LLM、第三方模型、概率模型或公开数据，而不是 Alpha 人工分析师；
- 不连接券商、不自动下单、只提供“只读交易计划”；
- 由客户自带模型 API key，但 Alpha 仍提供证券专用提示、建议卡、行情和工作流；
- 只向企业客户或小规模封闭客户销售，但客户仍是建议接受者且 Alpha 从中获利；
- 将证券模块免费赠送、与其他功能捆绑，或用广告、引流、会员升级等方式间接获利。

证监会官方材料没有为上述形式安排提供豁免；特别是“投资者教育”案例和“量化数据统计”抗辩未获采纳，说明名称和外壳不能替代对实际功能的审查。

## 六、仍需律师或监管确认的问题

1. **纯通用对话的最低控制标准。** Alpha 删除所有证券专用功能并对具体建议设置拒答后，极少数越狱或模型失误是否仍会使整个软件被视为“具备”荐股功能；目前未找到证监会对通用生成式 AI 的公开安全港或测试标准。
2. **用户主动生成内容的归责。** 用户完全自行编写提示、Alpha 不策划也不推广证券用途时，Alpha 与具体回答之间的产品/经营联系如何判断。
3. **通用订阅费的经济利益关联。** 真正的跨行业通用订阅费与偶发股票问答之间需要怎样隔离，才能不被视为因提供荐股软件直接或间接获利。
4. **BYOK、本地直连和客户自建 Skill。** 用户自带模型账户、数据不经过 Alpha 云端且证券提示由用户独立创建时，Alpha 是通用工具提供者还是证券咨询功能提供者；如果 Alpha 分发、审核、运营或收费提供该 Skill，风险会明显上升。
5. **持牌机构 B2B 技术外包。** 持牌机构应掌握哪些提示、模型、审核、签约收费和客户触点，才能由其而非 Alpha 被认定为投资咨询服务主体。
6. **事实边界测试。** 上线前应由中国证券律师按真实安装包、默认 Skill、销售话术、演示账号、价格表和输出样本出具书面意见，不能只审查服务协议。

## 七、建议的产品决策

如果目标是近期以无牌主体上线中国市场，建议采用明确的双轨方案：

- **通用版：** 删除所有证券专用建议模板、建议卡和持仓决策功能；只保留通用工作区，以及事实型证券信息汇总/历史数据统计；对具体证券分析、选择、买卖时机及仓位建议进行技术拒答。
- **持牌版：** 证券功能只在经审核的持牌机构租户中启用，由持牌机构承担真实投顾服务主体责任，并以租户级功能开关、提示版本、人员权限、审核和留痕证明隔离。

因此，用户提出的“通用 LLM 也能答股票”可以支持把 Alpha 改造成真正的通用工具，但**不能为当前已经产品化的具体证券建议功能提供当然免责**。
