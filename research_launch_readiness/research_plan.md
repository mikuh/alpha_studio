# Alpha Studio 客户上线合规核查计划

## 主问题

Alpha Studio 作为面向中国客户的 A 股研究桌面产品、云端行情聚合服务和模型网关，在 2026 年正式上线前有哪些必须确认的外部合规与平台规则？

## 子问题

1. **中国金融与数据合规**
   - 核对证券投资咨询/荐股边界、生成式人工智能服务要求、个人信息与跨境数据、公开行情展示/再分发相关的现行官方规则。
   - 只使用政府、监管机构、交易所或数据源官方材料，区分明确义务与需律师确认的判断。

2. **OpenAI/Codex 商业使用边界**
   - 核对 API 支持地区、账号共享/转售、ChatGPT/Codex 账号凭据和第三方客户使用相关的官方条款或文档。
   - 只使用 OpenAI 官方来源。

## 综合方式

将外部规则与仓库中现有的模型网关、账号托管方式、市场数据聚合、客户授权及研究建议功能逐项映射，最终按上线阻断项、上线前必做项和可后续优化项分级。

## 用户澄清后的复核（2026-08-04）

1. 通用 LLM（例如豆包或 DeepSeek）本身也能回答股票问题。复核监管边界究竟取决于通用模型能力，还是 Alpha Studio 的产品化流程、提示词、界面、输出和收费方式。
2. Alpha Studio 不计划多人共享同一账号，而是代客户持有账号，每位用户使用自己的账号登录。分别核对用户自有账号直接登录、Alpha 为外部客户开设账号、凭据托管、订阅转售及支持地区要求。

3. Alpha Studio 仅收取一次性软件费和 Token 消耗费，不对股票推荐或策略单独收费。复核“证券功能不单独定价”能否排除或降低“直接或者间接获取经济利益”的认定，并区分无加价成本转付、Token 加价和软件功能捆绑收费。

综合结论必须明确收窄或撤回不再适用于澄清事实的原表述。
