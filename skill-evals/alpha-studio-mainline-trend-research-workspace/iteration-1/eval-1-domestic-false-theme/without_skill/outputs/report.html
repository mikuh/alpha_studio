Framework

判定框架与证据纪律

P1 政策硬度｜权重 25%

区分正式政策、可执行制度改善与泛化支持表述。正式设备更新政策强于部委支持性表述。

P2 产业落地/项目资金｜权重 35%

项目贷款、付款、连续招标、订单或经营兑现构成产业硬证据；并购基金只算资本落地，不能替代经营现金流。

P3 长线机构资金｜权重 25%

连续增配才可确认边际方向。单期公募持仓只能证明“某期存在”，不能推出趋势。

P4 市场结构｜权重 15%

持续性、承接、扩散质量优于单日涨停潮。未提供行情时标为未知，不臆测。

评分与权限映射

单柱分值含义纪律
3.0强确认，且边际连续或具正式约束可承担主线确认
2.0中等确认，已有实质动作但链条不完整需第二证据交叉验证
1.0弱确认、单期或仅方向性表述不能独立开启重仓
0.0明确给定为缺失/不存在视作硬门槛未通过
未知用户未提供，不等于负面按零计入权限指数，但保留“待证”
主线硬门槛：P2 至少出现一项可核验产业落地证据；不少于两根独立支柱为正；重仓还需 P3 连续性或更强的 P2 现金流/订单链。只出现“支持表述 + 涨停潮”自动进入伪题材池。

证据使用边界

  • 本报告仅重述用户提供的假设，不新增证券、日期、金额、政策名称或外部出处。
  • 所有“连续”只沿用输入中明确给出的连续性；未给持续期的连续招标不擅自写成具体月数。
  • 指数 = Σ（支柱分值 ÷ 3 × 权重）；未知按 0 计入权限，防止缺失信息被乐观填充。

结构优势：相比电网设备，创新药的 P3 更强——连续两个月的保险资金增配能说明边际方向；相比低空经济，它拥有真实资本部署，不是只有口号与短线涨停。
重仓阻断点：并购基金属于资本动作，但题设没有给出临床、获批、授权交易、收入、订单、医保放量或项目付款。P2 因此只计中低强度，不能单靠长线增配升级为重仓主线。

升级 / 降级触发

升级至有条件重仓
  • 出现可核验经营兑现或产业现金流证据
  • 保险资金连续性延续且口径可比
  • 市场承接形成持续结构，而非单日脉冲
降级为观察
  • 医保改善未进入执行
  • 并购基金停留在设立而无部署
  • 保险资金连续增配中断或口径不可比

最大证据缺口

资本投入向经营兑现的传导证据。当前可以确认“钱在配置/工具在建立”，不能确认“产业现金流已经改善”。

检查项结果证据与解释

伪题材判定：“部委支持表述 → 涨停潮”是一条叙事—价格自强化链，缺少项目资金与付款这一外部锚。它可以形成交易事件，但在本框架下不能被认证为产业主线。

解除过滤所需最小证据集

  1. 正式、可执行且对象清晰的政策文件；
  2. 至少一项独立产业硬证据：项目贷款、实际付款、连续招标/订单或资本开支；
  3. 长线资金连续配置或可核验的市场持续承接，两者至少其一；
  4. 证据时间与口径可比，排除仅由涨停反向制造“产业景气”的循环论证。

最大证据缺口

产业侧真实资金流：贷款、付款或订单。这是从“支持性叙事”跨越到“可验证产业趋势”的决定性缺口，也是三主题中最严重的单项缺口。

权限等级

L0｜观察

不得建立主线仓位；可记录触发证据。

L1｜试探

有一项硬证据但尚未双柱确认。

L2｜标准仓/候选

多柱确认，但关键产业或市场链未闭合。

L3｜有条件重仓

P2 强通过且至少双柱；对证据缺口设置降级阈值。
